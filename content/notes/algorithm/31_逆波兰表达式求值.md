# 逆波兰表达式求值 — 学习笔记

- **日期：** 2026-07-23
- **题目：** [150. Evaluate Reverse Polish Notation](https://leetcode.cn/problems/evaluate-reverse-polish-notation/)
- **难度：** 中等
- **模式归类：** 栈（表达式求值）
- **题解：** [B站视频](https://www.bilibili.com/video/BV1kd4y1o7on/)

---

## 核心思想

```
遇到数字 → push 到栈
遇到运算符 → pop 两个数字运算 → 结果 push 回栈
最后栈顶 = 答案
```

---

## 图解

```
tokens = ["2", "1", "+", "3", "*"]    = (2+1)×3 = 9

2 → push        栈: [2]
1 → push        栈: [2, 1]
+ → pop 1, pop 2 → 2+1=3 → push    栈: [3]
3 → push        栈: [3, 3]
* → pop 3, pop 3 → 3×3=9 → push    栈: [9]
返回 9 ✅
```

---

## 代码

```java
class Solution {
    public int evalRPN(String[] tokens) {
        Deque<Integer> stack = new ArrayDeque<>();

        for (String c : tokens) {
            if (c.equals("+")) {
                int a = stack.pop();
                int b = stack.pop();
                stack.push(a + b);
            } else if (c.equals("-")) {
                int a = stack.pop();
                int b = stack.pop();
                stack.push(b - a);        // 先入栈的是左操作数
            } else if (c.equals("*")) {
                int a = stack.pop();
                int b = stack.pop();
                stack.push(a * b);
            } else if (c.equals("/")) {
                int a = stack.pop();
                int b = stack.pop();
                stack.push(b / a);        // 先入栈的是左操作数
            } else {
                stack.push(Integer.parseInt(c));
            }
        }
        return stack.pop();
    }
}
```

---

## 关键点

1. **减法和除法的顺序**：先 pop 出来的是右操作数，后 pop 的是左操作数
   - `b - a`（b 先入栈，是左边的数）
   - `b / a`
   - `a + b` 和 `a * b` 交换律不区分顺序
2. `Integer.parseInt(t)` — 将字符串数字转成整数
3. 为什么叫"逆波兰"：运算符写在操作数后面（`1 2 +`），不用括号
4. 时间复杂度 O(n)，空间复杂度 O(n)

## 对比：中缀 vs 后缀

| 类型 | 写法 | 例子 |
|------|------|------|
| 中缀（日常） | 运算符在中间 | `(2+1)×3` |
| 后缀（逆波兰） | 运算符在后面 | `2 1 + 3 *` |

后缀表达式不需要括号，天然适合栈运算。
