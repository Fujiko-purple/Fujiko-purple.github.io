## 核心思想

两端双指针，两两交换字符。和有序数组的平方一样的思路，只是把平方操作换成了交换。

```
 h   e   l   l   o
 ↑               ↑
left           right

交换 → o e l l h → left++ right--
交换 → o l l e h → 相遇，结束
```

---

## 代码

```java
public void reverseString(char[] s) {
    int left = 0, right = s.length - 1;
    while (left < right) {
        char temp = s[left];
        s[left] = s[right];
        s[right] = temp;
        left++;
        right--;
    }
}
```

---

## 关键点

1. `void` — 原地修改数组，不需要返回值
2. `char[]` — 字符数组，和 `int[]` 一样操作
3. 临时变量 `temp` 交换 — 跟反转链表、两两交换链表一样的模式
4. 时间复杂度 O(n)，空间 O(1)
