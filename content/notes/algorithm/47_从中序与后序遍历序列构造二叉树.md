## 题目
给定一棵二叉树的中序和后序遍历结果，构造并返回这棵二叉树。

```
中序：   [9, 3, 15, 20, 7]
后序：   [9, 15, 7, 20, 3]

还原：
        3
       / \
      9  20
        /  \
       15   7
```

## 核心思想
**后序找根，中序分左右**。后序的最后一个元素就是当前子树的根节点，拿着根节点去中序中分割出左右子树，递归构造。

## 关键步骤
1. 后序最后一个元素 = 当前根节点
2. 在中序中找到根的位置 → 左边全归左子树，右边全归右子树
3. 左子树长度 = 根在中序中的位置 - 中序左边界
4. 按左子树长度切分后序数组：前 leftSize 个归左子树，直到 postEnd-1 归右子树
5. 递归重复

## 分治图解（以题目为例）

```
第 1 轮：
  post [9, 15, 7, 20, 3] → 根 = 3
  in   [9,  3, 15, 20, 7] → 左[9], 右[15,20,7]
         |__↑__|
       左size=1

第 2 轮（右子树）：
  post [15, 7, 20] → 根 = 20
  in   [15, 20, 7] → 左[15], 右[7]

第 3 轮（右子树）：
  post [15] → 根 = 15，左右空
  post [7]  → 根 = 7， 左右空
```

## 时空复杂度

| 项目 | 复杂度 | 推导 |
|------|--------|------|
| 时间 | O(n²) 最坏 | 每轮线性扫描中序找根（可用 HashMap 优化为 O(n)） |
| 空间 | O(h) | 递归栈深度 |

## 模式归类：二叉树-遍历重构（后序定根 + 中序分割 + 递归构造）

## Java 代码

### 基础版（线性查找中序根位置）
```java
public TreeNode buildTree(int[] inorder, int[] postorder) {
    return build(inorder, 0, inorder.length - 1,
                 postorder, 0, postorder.length - 1);
}

TreeNode build(int[] inorder, int inStart, int inEnd,
               int[] postorder, int postStart, int postEnd) {

    if (inStart > inEnd || postStart > postEnd) return null;

    int rootVal = postorder[postEnd];          // 后序最后一个 = 根
    TreeNode root = new TreeNode(rootVal);

    // 在中序中找到根的位置（线性扫描）
    int rootIndex = inStart;
    for (int i = inStart; i <= inEnd; i++) {
        if (inorder[i] == rootVal) {
            rootIndex = i;
            break;
        }
    }

    int leftSize = rootIndex - inStart;  // 左子树长度 = 桥梁

    root.left = build(inorder, inStart, rootIndex - 1,
                      postorder, postStart, postStart + leftSize - 1);
    root.right = build(inorder, rootIndex + 1, inEnd,
                       postorder, postStart + leftSize, postEnd - 1);

    return root;
}
```

### 优化版（HashMap + 全局下标）
```java
Map<Integer, Integer> inMap = new HashMap<>();

public TreeNode buildTree(int[] inorder, int[] postorder) {
    // 预处理：值和位置的映射
    for (int i = 0; i < inorder.length; i++) {
        inMap.put(inorder[i], i);
    }
    return build(postorder, 0, postorder.length - 1, 0, inorder.length - 1);
}

TreeNode build(int[] postorder, int postStart, int postEnd,
               int inStart, int inEnd) {

    if (inStart > inEnd || postStart > postEnd) return null;

    int rootVal = postorder[postEnd];
    TreeNode root = new TreeNode(rootVal);

    int rootIndex = inMap.get(rootVal);        // O(1) 查找
    int leftSize = rootIndex - inStart;

    root.left = build(postorder, postStart, postStart + leftSize - 1,
                      inStart, rootIndex - 1);
    root.right = build(postorder, postStart + leftSize, postEnd - 1,
                       rootIndex + 1, inEnd);

    return root;
}
```

## 易错点
1. ⚠️ 后序根在 `postEnd`，不是 `postStart`
2. 左子树长度的计算：`rootIndex - inStart`，这是切分后序的关键桥梁
3. 后序右子树右边界 = `postEnd - 1`（排除根），不是 `postEnd`
4. 递归出口：区间不合法（`start > end`）时返回 null

## 前序 + 中序也能构造
同理：**前序第一个 = 根**，中序分左右。只有"前序 + 后序"无法唯一确定树。
