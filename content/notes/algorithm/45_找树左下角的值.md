# 找树左下角的值（LeetCode 513）

## 题目
给定二叉树的根节点 root，返回二叉树**最底层最左边**节点的值。

```
        1
       / \
      2   3
     /   / \
    4   5   6
       /
      7

最底层 = 第 4 层（节点 7），最左边 = 7 → 输出 7
```

## 核心思想
找到最深的一层，取该层最左边的节点。**深度优先于左优先**——如果最深层只有右节点没有左节点，右节点就是答案。

## 关键步骤
1. 遍历二叉树，同时维护当前深度
2. 记录最深层的第一个访问到的节点
3. 返回记录的节点值

## 时空复杂度

| 项目 | 复杂度 | 推导 |
|------|--------|------|
| 时间 | O(n) | 每个节点访问一次 |
| 空间 | O(h) | BFS 队列 O(w)，DFS 递归栈 O(h) |

## 模式归类：二叉树-遍历维护最优值（全局变量+更优则更新）

## Java 代码

### BFS（层序遍历，更直观）
```java
public int findBottomLeftValue(TreeNode root) {
    Queue<TreeNode> queue = new LinkedList<>();
    queue.offer(root);
    int result = 0;

    while (!queue.isEmpty()) {
        int size = queue.size();
        for (int i = 0; i < size; i++) {
            TreeNode node = queue.poll();
            if (i == 0) result = node.val;  // 每层第一个 = 最左边
            if (node.left != null) queue.offer(node.left);
            if (node.right != null) queue.offer(node.right);
        }
    }
    return result;  // 最后出循环时 result 是最后一层的第一个
}
```

### DFS（前序遍历，更短）
```java
int maxDepth = -1;
int result = 0;

public int findBottomLeftValue(TreeNode root) {
    dfs(root, 0);
    return result;
}

void dfs(TreeNode node, int depth) {
    if (node == null) return;

    if (node.left == null && node.right == null) {
        if (depth > maxDepth) {
            maxDepth = depth;     // 更新最深深度
            result = node.val;    // 记录当前值
        }
        return;
    }

    dfs(node.left,  depth + 1);
    dfs(node.right, depth + 1);
}
```

## 易错点
1. ⚠️ 优先最深，不是优先最左——第一反应是"取最左"就错了
2. DFS 写法必须确保**前序遍历**，先左后右，这样同一层左边先到达，右边不会覆盖
3. BFS 写法中 `i == 0` 取的是一层中第一个出队的节点（最左边）
