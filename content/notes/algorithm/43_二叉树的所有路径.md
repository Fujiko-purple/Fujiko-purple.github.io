## 题目
给你一棵二叉树的根节点 root，按任意顺序返回所有从根到叶子节点的路径。

```
    1
   / \
  2   3
   \
    5

输出：["1->2->5", "1->3"]
```

## 核心思想
深度优先遍历，沿途拼接路径字符串。遇到叶子节点时把完整路径保存到结果列表。

## 关键步骤
1. 空节点 → 直接返回
2. 叶子节点（左右都为 null）→ 当前路径加上自身值，保存到结果
3. 非叶子节点 → 当前路径加上自身值和 `"->"`，传给左右孩子

## 时空复杂度

| 项目 | 复杂度 | 推导 |
|------|--------|------|
| 时间 | O(n) | 每个节点访问一次（路径拼接 O(k)，整体 O(n²)） |
| 空间 | O(n) | 结果列表 + 递归栈 |

## 模式归类：二叉树-路径回溯（字符串拼接）

## Java 代码

### 简单法（字符串拼接，面试够用）
```java
public List<String> binaryTreePaths(TreeNode root) {
    List<String> result = new ArrayList<>();
    traverse(root, "", result);
    return result;
}

void traverse(TreeNode node, String path, List<String> result) {
    if (node == null) return;

    if (node.left == null && node.right == null) {
        result.add(path + node.val);
        return;
    }

    traverse(node.left,  path + node.val + "->", result);
    traverse(node.right, path + node.val + "->", result);
}
```

### 优化法（StringBuilder + 回溯）
```java
public List<String> binaryTreePaths(TreeNode root) {
    List<String> result = new ArrayList<>();
    dfs(root, new StringBuilder(), result);
    return result;
}

void dfs(TreeNode node, StringBuilder sb, List<String> result) {
    if (node == null) return;

    int len = sb.length();
    sb.append(node.val);

    if (node.left == null && node.right == null) {
        result.add(sb.toString());
    } else {
        sb.append("->");
        dfs(node.left,  sb, result);
        dfs(node.right, sb, result);
    }

    sb.setLength(len);  // 回溯恢复
}
```

## 易错点
1. 叶子才保存路径，非叶子节点只负责传递
2. 字符串拼接法每次创建新 String，好在代码简单清晰
3. StringBuilder 方式必须记得回溯 `setLength(len)`，否则路径会叠加
