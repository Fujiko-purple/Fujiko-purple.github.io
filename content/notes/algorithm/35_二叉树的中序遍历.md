# 二叉树的中序遍历 — 学习笔记

- **日期：** 2026-07-24
- **题目：** [94. Binary Tree Inorder Traversal](https://leetcode.cn/problems/binary-tree-inorder-traversal/)
- **难度：** 简单
- **模式归类：** 二叉树 / 递归遍历
- **题解：** [B站视频](https://www.bilibili.com/video/BV1Zf4y1a77g/)

---

## 核心思想

```
中序（左根右）：左子树 → 根 → 右子树

add 写在中间 = 中序
```

## 三种遍历对比

```
       1
      / \
     2   3
    / \
   4   5

中序：4→2→5→1→3    （根在中间）
```

---

## 代码

```java
class Solution {
    List<Integer> res = new ArrayList<>();
    public List<Integer> inorderTraversal(TreeNode root) {
        if (root == null) return res;
        inorderTraversal(root.left);    // ① 左
        res.add(root.val);              // ② 根
        inorderTraversal(root.right);   // ③ 右
        return res;
    }
}
```

## 关键点

1. 跟前序、后序**完全相同的结构**，只是 add 的位置换到中间
2. `if (root == null) return res` — 递归终止条件
3. 时间复杂度 O(n)
