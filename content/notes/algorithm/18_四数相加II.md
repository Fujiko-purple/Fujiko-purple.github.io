# 四数相加 II — 学习笔记

- **日期：** 2026-07-18
- **题目：** [454. 4Sum II](https://leetcode.cn/problems/4sum-ii/)
- **难度：** 中等
- **模式归类：** 哈希表-HashMap（分组 + 两数之和变体）
- **题解：** [B站视频](https://www.bilibili.com/video/BV1Md4y1Q7Yh/)

---

## 核心思想

将四个数组**两两分组**，转化为两数之和问题：

```
nums1[i] + nums2[j] + nums3[k] + nums4[l] = 0
                ↓
     (A+B)  +  (C+D)  =  0
                ↓
       A+B   =  -(C+D)
```

1. 遍历 A+B 所有组合，和存入 HashMap（**和 → 出现次数**）
2. 遍历 C+D 所有组合，在 HashMap 中查找 `-(C+D)`，累加次数

时间复杂度从 O(n⁴) 降到 O(n²)。

---

## 代码

```java
public int fourSumCount(int[] nums1, int[] nums2, int[] nums3, int[] nums4) {
    HashMap<Integer, Integer> map = new HashMap<>();
    int count = 0;

    // 第一部分：A+B 的所有和，统计出现次数
    for (int i = 0; i < nums1.length; i++) {
        for (int j = 0; j < nums2.length; j++) {
            int sum = nums1[i] + nums2[j];
            map.put(sum, map.getOrDefault(sum, 0) + 1);
        }
    }

    // 第二部分：C+D 取相反数，去 map 里找匹配
    for (int i = 0; i < nums3.length; i++) {
        for (int j = 0; j < nums4.length; j++) {
            int target = -(nums3[i] + nums4[j]);
            count += map.getOrDefault(target, 0);
        }
    }

    return count;
}
```

---

## 关键点

1. **为什么存次数而不是只存是否存在？** 不同 (i,j) 组合可能算出相同的和，每种都要算
2. `getOrDefault(key, 0)` — key 存在返回值，不存在返回默认值 0
3. `map.put(sum, getOrDefault(sum, 0) + 1)` — 给和计数，出现过就 +1，没出现就设为 1
4. `count += map.getOrDefault(target, 0)` — 有几组 A+B 能配对，就加几

---

## 对比：两数之和 vs 四数相加 II

| | 两数之和 | 四数相加 II |
|------|------|------|
| 找什么 | target - nums[i] | -(C+D) |
| HashMap 存什么 | 值 → 下标 | 和 → 次数 |
| 返回值 | 下标数组 | 组合个数 |
| 查询时 | containsKey 判断存在 | getOrDefault 累加次数 |
