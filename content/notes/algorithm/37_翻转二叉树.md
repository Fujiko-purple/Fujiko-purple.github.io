# 翻转二叉树（LeetCode 226）

## 题目
给你一棵二叉树的根节点 `root`，翻转这棵二叉树，并返回其根节点。

```
输入：     4             输出：     4
         /   \                  /   \
        2     7               7     2
       / \   / \             / \   / \
      1   3 6   9           9   6 3   1
```

## 核心思想
整棵树的翻转 = 当前节点左右孩子互换 + 左右子树各自翻转，递归到空节点为止。

## 关键步骤
1. **终止条件**：当前节点为空（`null`），直接返回 `null`
2. **翻转子问题**：递归翻转左子树、递归翻转右子树
3. **交换**：当前节点的 `left` = 翻转后的右子树，`right` = 翻转后的左子树
4. **返回**：当前节点

## 时空复杂度

| 项目 | 复杂度 | 推导 |
|------|--------|------|
| 时间 | O(n) | 每个节点恰好访问一次 |
| 空间 | O(h) | 递归栈深度 = 树高，最坏退化成链表 O(n)，平均 O(log n) |

## 模式归类：二叉树-递归翻转

## Java 代码

### 递归（DFS）
```java
public TreeNode invertTree(TreeNode root) {
    // 终止条件：空节点
    if (root == null) {
        return null;
    }
    // 先递归翻转左右子树
    TreeNode left = invertTree(root.left);
    TreeNode right = invertTree(root.right);
    // 交换当前节点的左右孩子
    root.left = right;
    root.right = left;
    // 返回翻转后的根节点
    return root;
}

class Solution {
        public TreeNode invertTree(TreeNode root) {
            //基准条件
            if (root == null)return null;

            //建立临时变量方便交换左右节点
            TreeNode temp = root.left;
            root.left = root.right;
            root.right = temp;

            //进行递归 递归下降
            invertTree(root.left);
            invertTree(root.right);

            return root;
        }
    }
```

### BFS（层序 + 队列，非递归）
```java
public TreeNode invertTree(TreeNode root) {
    if (root == null) return null;
    Queue<TreeNode> queue = new LinkedList<>();
    queue.offer(root);
    while (!queue.isEmpty()) {
        TreeNode node = queue.poll();
        // 交换左右孩子
        TreeNode tmp = node.left;
        node.left = node.right;
        node.right = tmp;
        // 入队下一层
        if (node.left != null)  queue.offer(node.left);
        if (node.right != null) queue.offer(node.right);
    }
    return root;
}
```

### 遍历顺序对比
- **前序**：先交换当前节点，再递归子树 ✓
- **后序**：先递归子树，再交换当前节点 ✓
- **中序**：左 → 交换 → 右（交换后原来的右变成了左），**需要小心**

## 易错点
1. 递归时**必须先保存子树引用**再赋值，否则交换后会丢失引用
2. 注意空节点判断，否则 NullPointerException
