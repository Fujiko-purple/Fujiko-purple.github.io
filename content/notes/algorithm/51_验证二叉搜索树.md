## 题目
判断一棵二叉树是否是合法的二叉搜索树（BST）。

```
合法 BST：
        5
       / \
      1   8
         / \
        6   9

非法 BST（4 在 5 右子树却小于 5）：
        5
       / \
      1   6
         / \
        4   7
```

## 核心思想
**传递 min/max 范围约束**。每往左走，更新上限为当前节点值；每往右走，更新下限为当前节点值。子树所有节点必须在范围内。

## 关键步骤
1. 空节点 → 合法，返回 true
2. 当前节点值不在 [min, max] 范围内 → 返回 false
3. 递归左子树：范围变成 [min, root.val]
4. 递归右子树：范围变成 [root.val, max]

> 为什么用 long 不用 int？防止节点值等于 Integer.MIN_VALUE 时被误判。

## 时空复杂度

| 项目 | 复杂度 | 推导 |
|------|--------|------|
| 时间 | O(n) | 每个节点访问一次 |
| 空间 | O(h) | 递归栈深度 |

## 模式归类：BST-范围约束（min/max 传递法）

## Java 代码

```java
public boolean isValidBST(TreeNode root) {
    return isValid(root, Long.MIN_VALUE, Long.MAX_VALUE);
}

boolean isValid(TreeNode node, long min, long max) {
    if (node == null) return true;                // 空节点合法

    if (node.val <= min || node.val >= max) {     // 超出范围
        return false;
    }

    // 左子树：上限变成当前节点值
    // 右子树：下限变成当前节点值
    return isValid(node.left, min, node.val) &&
           isValid(node.right, node.val, max);
}
```

## 易错点
1. ⚠️ 不能只检查 `root.left.val < root.val < root.right.val`——必须保证**所有**左子树/右子树节点都满足
2. ⚠️ 用 `<=` 和 `>=` 而不是 `<` 和 `>`——BST 要求严格大于/小于，相等也不合法
3. 必须用 `long` 类型存边界，否则 `Integer.MIN_VALUE` 会初始就被判非法
4. 中序遍历 BST 得到的是升序序列——也可以用中序遍历解法，但范围传递法更直观
