# 反转字符串中的单词 — 学习笔记

- **日期：** 2026-07-20
- **题目：** [151. Reverse Words in a String](https://leetcode.cn/problems/reverse-words-in-a-string/)
- **难度：** 中等
- **模式归类：** 双指针缝合怪（快慢指针 + 两端双指针）
- **题解：** [B站视频](https://www.bilibili.com/video/BV1uT41177fX/)

---

## 核心思想

三步走，每一步你都会：

```
输入: "the sky is blue"
  ↓ ① 去空格（快慢指针）
"the sky is blue"
  ↓ ② 整个反转（两端双指针）
"eulb si yks eht"
  ↓ ③ 逐个单词反转回来（两端双指针）
"blue is sky the"
```

---

## 代码

```java
class Solution {
    public String reverseWords(String s) {
        char[] arr = s.toCharArray();
        int len = arr.length;

        // ① 去除多余空格（快慢指针）
        int slow = 0;
        for (int fast = 0; fast < len; fast++) {
            if (arr[fast] != ' ') {                     // 快指针找到单词开头
                if (slow != 0) {                        // 不是第一个单词 → 加空格
                    arr[slow] = ' ';
                    slow++;
                }
                while (fast < len && arr[fast] != ' ') { // 复制整个单词
                    arr[slow] = arr[fast];
                    slow++;
                    fast++;
                }
            }
        }

        // ② 整个字符串反转
        reverse(arr, 0, slow - 1);

        // ③ 逐个单词反转
        int start = 0;
        for (int i = 0; i <= slow; i++) {               // 注意是 <= slow，为了处理最后一个
            if (i == slow || arr[i] == ' ') {
                reverse(arr, start, i - 1);
                start = i + 1;
            }
        }

        return new String(arr, 0, slow);
    }

    private void reverse(char[] arr, int left, int right) {
        while (left < right) {
            char temp = arr[left];
            arr[left] = arr[right];
            arr[right] = temp;
            left++; right--;
        }
    }
}
```

## 三道工序拆解

| 工序 | 用到的技巧 | 来自哪道题 |
|------|------|------|
| ① 去空格 | 快慢指针 | 移除元素 |
| ② 整个反转 | 两端双指针 | 反转字符串 |
| ③ 单词反转 | 同上 | 反转字符串 |

## 关键细节

| 细节 | 解释 |
|------|------|
| `if (slow != 0)` 才加空格 | 第一个单词前面不加空格 |
| `i <= slow` | 为处理最后一个单词（后面没空格，靠 `i==slow` 触发） |
| `i == slow` 要在 `\|\|` 左边 | 短路求值防越界 |
| `reverse(arr, 0, slow-1)` | slow=有效长度，下标减 1 |
