## 题目
给一棵**普通二叉树**和两个节点 p、q，返回它们的最近公共祖先。p、q 一定在树里。

最近公共祖先：离 p、q 都最近的共同祖先（节点可以是自己的祖先）。

## 核心思想
判断「谁是 LCA」需要的信息（p、q 在不在子树里）是**自底向上**才知道的
→ 用**后序遍历**（左→右→根），左右子树都跑完拿到结果，自己再判断。

## 示例树（本文所有推演都用它）
```
       3
      / \
     5   1
    / \   \
   6   2   8
      / \
     7   4
```
- p=5, q=4 → LCA = **5**（5 自己是 p，直接返回自己）
- p=7, q=4 → LCA = **2**（7、4 分居 2 两侧，2 是分岔点）
- p=6, q=8 → LCA = **3**（一个在左子树一个在右子树）

## 递归返回值设计（关键）
`dfs(node)` 返回「这棵子树里发现了什么」：

| 情况 | 返回 |
|------|------|
| 子树里什么都没有 | null |
| 发现了 p 或 q | 返回那个节点 |
| 找到了 LCA | 返回 LCA 节点（一路传到根） |

## 关键步骤
1. 后序遍历：先 `left = dfs(node.left)`，再 `right = dfs(node.right)`
2. 判断规则（顺序重要）：
   - `node == null` → null
   - `node == p || node == q` → 返回 **node**（自己是目标，直接返回，不能丢）
   - `left != null && right != null` → 返回 **node**（p、q 分居两侧，node 是分岔点 = LCA）
   - 只有一边非 null → 返回那一边（把发现上传）

## 为什么③必须写在④前面
假设没有「自己是目标」的判断：p=5, q=4 时站在节点 5，
left=null，right=4(q) → 只会上传 4，**把 5 自己丢了**。
有了③，走到 5 发现 `node == p` 直接返回自己。
目标节点自身永远不能丢。

## 为什么单边返回用变量而不是 root.left
发现可能来自子树**深处**（比如 p=7, q=9 时，3 的左子树上传上来的是 2，
而 `root.left` 是 5）。`root.left` 只是左孩子引用，不是左子树上传的结果。

## 复杂度
- 时间 O(n)：每个节点访问一次
- 空间 O(h)：递归栈深

## Java 代码
```java
class Solution {
    public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
        if (root == null) return null;

        TreeNode left = lowestCommonAncestor(root.left, p, q);   // 后序：先左
        TreeNode right = lowestCommonAncestor(root.right, p, q); // 后序：再右

        if (root == p || root == q) return root;   // 自己是目标，直接返回

        if (left != null && right != null) return root;  // p、q 分居两侧 → 分岔点
        return left != null ? left : right;              // 单边发现 → 上传
    }
}
```

## 易错点
1. 返回值用 `int` 接收 → 编译错误，必须是 `TreeNode`
2. 比较用 `root == p`（引用比较），不是 `root.val == p`（类型都不匹配；
   而且树里值可能重复，引用唯一）
3. 单边返回必须返回 `left`/`right` 变量，不是 `root.left`/`root.right`
4. 函数末尾要兜底 return（三元运算符一行搞定）
5. 遍历顺序必须是后序，不能用前序（自己还没看子树就判断，信息不足）
6. **③⑤缺一不可**（反向推演证明）：
   - 缺③（自己是 p/q 就返回自己）：p=5, q=4 站在 5，
     left=null，right=4(q) → 只会上传 4，把 5 自己丢了
   - 缺⑤（单边发现要上传，只留 return null 兜底）：p=6, q=4 站在 2，
     right=4(q) 但④不满足 → 兜底返回 null，**q 在 2 这层被弄丢**，
     答案传到根变成 null
   - 总结：③ 防「丢自己」，⑤ 防「丢子树里的目标」，④ 识别分岔点，
     三个职责互不重叠，缺一个答案就错
