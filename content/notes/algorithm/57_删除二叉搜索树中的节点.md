# 57 · 删除二叉搜索树中的节点

> LeetCode 450 | 中等 | 标签：二叉搜索树

## 核心思想（一句话）

**删除 = 改指针**：不是物理抹掉节点，而是让父节点的指针指向"新主人"——叶子给 null，独子给孩，两子给接班人。

## 三种情况

| 情况 | 子节点 | 返回值（新主人） | 难度 |
|:--:|:--:|------|:--:|
| ① 叶子 | 0 个 | `return null`（父指针断开，节点消失） | 简单 |
| ② 独子 | 1 个 | `return root.left` / `root.right`（孩子顶替上位） | 简单 |
| ③ 两子 | 2 个 | 值顶替 + 删原接班人 | 麻烦 |

## 树图示例

### 情况②：删 5（独子，左孩子 3 顶替）

```
删前：              删后：
       8               8
      /               /
     5      →        3
    /               / \
   3               1   4
  / \
 1   4
```

### 情况③：删 8（两子，接班人 = 右子树最小 = 10）

```
原树：                 第一步 值顶替（出现两个 10！）：
       8                   10
     /   \               /   \
    4     12            4     12
   / \   /  \          / \   /  \
  2   6 10  14        2   6 10  14   ← 原 10 还在（重复）

第二步 递归删掉原 10（它在 12 的左子树里，无左孩子 → 走情况①）：
       10
     /   \
    4     12
   / \      \
  2   6     14   ← 干净了
```

## 关键步骤（情况③三步走）

1. **找接班人**：successor = 右子树最小节点（一路往左走到底）
   - 为什么是它：比左子树所有人都大，比右子树剩余所有人都小 → 坐根合法
   - 为什么没负担：它没有左孩子 → 搬迁后最多只需处理一个右孩子
2. **拷贝值**：`root.val = successor.val` —— 只换数字，树形不变（此刻出现重复值）
3. **删原接班人**：`root.right = deleteNode(root.right, successor.val)`
   - 递归套娃，但接班人无左孩子 → 只会走情况①②，1-2 步结束，绝不无限循环

## 易错点

- `findMin` 条件是 `while (node.left != null)`，不是 `node != null`（后者会走到 null 才停，永远返回 null）
- `return root.right` 即可，别写 `return root = root.right`（多余赋值）
- 搜索阶段必须挂回：`root.left = deleteNode(root.left, key)`——子树删完可能变样（甚至变 null）

## 复杂度

- 时间：O(h)（h = 树高；平衡树 O(log n)，退化成链 O(n)）
- 空间：O(h)（递归栈）

## 最终代码

```java
class Solution {
    public TreeNode deleteNode(TreeNode root, int key) {
        if (root == null) return null;

        // 搜索阶段：没找到就往下走，并挂回结果（子树可能变样）
        if (key < root.val) {
            root.left = deleteNode(root.left, key);
        } else if (key > root.val) {
            root.right = deleteNode(root.right, key);
        } else {
            // 找到了，分三种情况
            if (root.left == null) {
                return root.right;        // ① 叶子 或 ② 只有右孩子
            } else if (root.right == null) {
                return root.left;         // ② 只有左孩子
            } else {
                // ③ 两个孩子：右子树最小节点接班
                TreeNode successor = findMin(root.right);
                root.val = successor.val;                        // 值顶替
                root.right = deleteNode(root.right, successor.val); // 删原接班人
            }
        }
        return root;
    }

    // 一路往左走到底 = 右子树最小节点
    TreeNode findMin(TreeNode node) {
        while (node.left != null) {
            node = node.left;
        }
        return node;
    }
}
```

## 一句话应用场景

数据库索引 / 有序集合（TreeMap）删除元素时，内部就是"找接班人值顶替，再删原接班人"。
