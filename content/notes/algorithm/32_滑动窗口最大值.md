# 滑动窗口最大值 — 学习笔记

- **日期：** 2026-07-23
- **题目：** [239. Sliding Window Maximum](https://leetcode.cn/problems/sliding-window-maximum/)
- **难度：** 困难
- **模式归类：** 队列 / 单调队列
- **题解：** [B站视频](https://www.bilibili.com/video/BV1XS4y1p7qj/)

---

## 核心思想

暴力：每个窗口重新找最大 → O(n×k)，太慢
单调队列：维持一个**从大到小**的队列，队头永远是窗口最大

```
新人入队 → 把队尾所有 ≤ 自己的踢掉（它们永远没机会了）
老人滑出 → 如果滑出的 == 队头，弹出队头
```

## 代码（模板）

```java
class Solution {
    public int[] maxSlidingWindow(int[] nums, int k) {
        int n = nums.length;
        int[] res = new int[n - k + 1];          // 结果数组
        Deque<Integer> dq = new ArrayDeque<>();  // 存下标！
        int idx = 0;

        for (int i = 0; i < n; i++) {
            // ① 滑出去了 → 队头弹出（如果滑出的刚好是队头）
            if (!dq.isEmpty() && dq.peekFirst() < i - k + 1) {
                dq.removeFirst();
            }

            // ② 新人来 → 把队尾 ≤ 新人的全踢掉
            while (!dq.isEmpty() && nums[dq.peekLast()] <= nums[i]) {
                dq.removeLast();
            }

            // ③ 新人入场（存的是下标）
            dq.addLast(i);

            // ④ 窗口满了 → 队头就是当前窗口最大
            if (i >= k - 1) {
                res[idx++] = nums[dq.peekFirst()];
            }
        }
        return res;
    }
}
```

---

## 关键点

1. **队列存下标不是值** — 存下标才能判断"滑出去了"
2. **①②③顺序不能换**：先弹旧的 → 再踢小的 → 最后新人入
3. `<=` 而不是 `<` — 等于自己的也踢掉，反正新人更靠右
4. 每个元素最多进一次出一 → O(n)
5. Deque 两端操作：`peekFirst/removeFirst/addLast/peekLast/removeLast`

## 代码拆解

| 行 | 作用 | 为什么 |
|----|------|--------|
| `peekFirst() < i-k+1` | 队头滑出窗口了 | `i-k+1` 是窗口左边界 |
| `removeLast()` + `<=` | 踢掉所有太小的 | 有更大的新人在，小的一辈子没机会 |
| `addLast(i)` | 存下标 | 方便判断滑出 |
| `peekFirst()` | 取答案 | 队头永远是最大 |
