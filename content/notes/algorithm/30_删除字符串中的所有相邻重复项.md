# 删除字符串中的所有相邻重复项 — 学习笔记

- **日期：** 2026-07-23
- **题目：** [1047. Remove All Adjacent Duplicates In String](https://leetcode.cn/problems/remove-all-adjacent-duplicates-in-string/)
- **难度：** 简单
- **模式归类：** 栈（消消乐/相邻消除）
- **题解：** [B站视频](https://www.bilibili.com/video/BV12a411P7mw)

---

## 核心思想

```
遍历每个字符 → 跟栈顶比
  相同 → pop（消掉相邻的一对）
  不同 → push（放进栈）
最后栈里剩下的拼起来就是结果
```

跟 29_有效的括号 本质一样，只是把"左右配对"换成了"相邻相同就消"。

---

## 图解

```
s = "abbaca"

a → push              栈: [a]
b → push              栈: [a, b]
b → 栈顶也是 b → pop  栈: [a]        ← bb 消掉
a → 栈顶也是 a → pop  栈: []         ← aa 消掉
c → push              栈: [c]
a → push              栈: [c, a]

剩余 "ca"（pop 出来是 ac，reverse 后是 ca）
```

---

## 代码

```java
class Solution {
    public String removeDuplicates(String s) {
        Deque<Character> stack = new ArrayDeque<>();

        for (char c : s.toCharArray()) {
            // 栈不空 且 当前 == 栈顶 → 消掉
            if (!stack.isEmpty() && stack.peek() == c) {
                stack.pop();
            } else {
                stack.push(c);
            }
        }

        // 栈里剩下的 pop 出来拼成字符串
        StringBuilder sb = new StringBuilder();
        while (!stack.isEmpty()) {
            sb.append(stack.pop());
        }
        // pop 出来是反的，reverse 纠正
        return sb.reverse().toString();
    }
}
```

---

## 关键点

1. 跟 29_有效的括号 同模板：遍历 → 比栈顶 → 匹配则 pop，不匹配则 push
2. 栈存的是**还没被消除的字符**
3. pop 出来的顺序是反的 → `reverse()` 纠正
4. 不要试图在原字符串上做（下标会乱）
5. 时间复杂度 O(n)，空间复杂度 O(n)
