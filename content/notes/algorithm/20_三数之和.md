## 核心思想

**排序 + 固定 a + 双指针找 b、c**

```
三数之和：a + b + c = 0
    ↓ 移项
    b + c = -a
    ↓
固定 a，在 a 右边用双指针找 b + c = -a
```

本质是把三数之和化归为**两数之和（双指针版）**。

---

## 代码

```java
public List<List<Integer>> threeSum(int[] nums) {
    List<List<Integer>> result = new ArrayList<>();
    Arrays.sort(nums);                               // 1. 排序

    for (int i = 0; i < nums.length; i++) {
        if (nums[i] > 0) break;                      // 2. 剪枝：最小数>0，不可能
        if (i > 0 && nums[i] == nums[i - 1]) continue; // 3. 去重 a

        int left = i + 1, right = nums.length - 1;
        while (left < right) {                       // 4. 双指针
            int sum = nums[i] + nums[left] + nums[right];

            if (sum < 0) left++;                     // 太小
            else if (sum > 0) right--;               // 太大
            else {                                   // 命中
                result.add(Arrays.asList(nums[i], nums[left], nums[right]));
                while (left < right && nums[left] == nums[left + 1]) left++;   // 5. 去重 b
                while (left < right && nums[right] == nums[right - 1]) right--; // 5. 去重 c
                left++; right--;
            }
        }
    }
    return result;
}
```

---

## 关键点

1. **排序是前提** — 排完序双指针才能按大小移动
2. **去重分三层** — a 的重复（外层 continue）、b 的重复（命中后跳过）、c 的重复（命中后跳过）
3. **时间复杂度 O(n²)** — 外层 O(n)，内层双指针 O(n)
4. 等价于：固定 a，剩下的就是"有序数组的两数之和"

## 新语法速查

| 语法 | 作用 |
|------|------|
| `Arrays.sort(nums)` | 数组升序排序 |
| `Arrays.asList(a, b, c)` | 快速生成 List |
| `List<List<Integer>>` | 嵌套泛型：外层列表的元素也是列表 |
| `break` | 跳出当前循环 |
| `continue` | 跳过本轮循环，进入下一轮 |
