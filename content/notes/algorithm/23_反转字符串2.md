## 核心思想

反转字符串（344）的升级版：每 2k 个字符为一组，反转每组的前 k 个。

```
循环：每次跳 2k 步
  每一段：反转前 k 个（如果不够 k 个，全反转）
```

---

## 代码

```java
public String reverseStr(String s, int k) {
    char[] arr = s.toCharArray();
    for (int i = 0; i < arr.length; i += 2 * k) {
        int left = i;
        int right = Math.min(i + k - 1, arr.length - 1);  // 反转边界，防越界
        while (left < right) {
            char temp = arr[left];
            arr[left] = arr[right];
            arr[right] = temp;
            left++; right--;
        }
    }
    return new String(arr);  // 字符数组 → 字符串
}
```

---

## 关键点

1. **`Math.min(i+k-1, arr.length-1)`** — 一句搞定所有边界判断：
   - 剩 ≥ k 个 → 取 `i+k-1`，反转 k 个
   - 剩 < k 个 → 取 `arr.length-1`，全反转
2. **`new String(arr)`** — 字符数组转回字符串，对应 `s.toCharArray()` 的逆向操作
3. **`i += 2*k`** — 不是 `i++`，每段跳 2k 步
4. 时间复杂度 O(n)，空间 O(n)（toCharArray 的副本）

## 对比 344 vs 541

| | 反转字符串 (344) | 反转字符串 II (541) |
|------|:--:|:--:|
| 反转范围 | 整个数组 | 每 2k 段的前 k 个 |
| 循环 | `while (left < right)` | `for (i+=2k)` + `while (left < right)` |
| 本质 | 双指针交换 | 分段 + 双指针交换 |
