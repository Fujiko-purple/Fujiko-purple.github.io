# 开发商购买土地 — 学习笔记

- **日期：** 2026-07-15
- **题目：** [卡码网 1044 开发商购买土地](https://kamacoder.com/problempage.php?pid=1044)
- **难度：** 中等
- **模式归类：** 前缀和（二维扩展）

---

## 核心思想

> 前缀和从一维扩展到二维：行方向累积（横切）、列方向累积（竖切）。各切一刀，对比两半的差距，找最小值。

---

## 关键步骤

1. 边读入矩阵边计算：
   - `total`：所有格子的和
   - `rowSum[i]`：第 i 行的元素和
   - `colSum[j]`：第 j 列的元素和
2. 横着切：行方向前缀和累加，每次计算 `|half - (total - half)|`
3. 竖着切：列方向前缀和累加，每次计算 `|half - (total - half)|`
4. 返回所有差值中最小的

---

## 时空复杂度

| 阶段 | 时间 | 空间 |
|------|------|------|
| 读入矩阵 | O(n×m) | O(n+m) — 只需行和列数组 |
| 横切计算 | O(n) | — |
| 竖切计算 | O(m) | — |
| **总计** | **O(n×m)** | **O(n+m)** |

---

## Java 代码

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int m = sc.nextInt();
        
        int[] rowSum = new int[n];  // 每行的和
        int[] colSum = new int[m];  // 每列的和
        int total = 0;
        
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < m; j++) {
                int val = sc.nextInt();
                total += val;
                rowSum[i] += val;
                colSum[j] += val;
            }
        }
        
        int minDiff = Integer.MAX_VALUE;
        int half = 0;
        
        // 横着切（行方向前缀和）
        for (int i = 0; i < n - 1; i++) {
            half += rowSum[i];
            int diff = Math.abs(half - (total - half));
            minDiff = Math.min(minDiff, diff);
        }
        
        // 竖着切（列方向前缀和）
        half = 0;
        for (int j = 0; j < m - 1; j++) {
            half += colSum[j];
            int diff = Math.abs(half - (total - half));
            minDiff = Math.min(minDiff, diff);
        }
        
        System.out.println(minDiff);
        sc.close();
    }
}
```
