## 核心思想

杂志里的每个字母只能用一次，看能不能拼出赎金信。

**供给与需求模型：**
- magazine = 仓库供货（每个字母 +1）
- ransomNote = 消耗需求（每个字母 -1）
- 如果某个字母库存不够（count < 0），返回 false

跟**有效的字母异位词**是同一套思路，区别在于：
- 异位词：两个串长度必须相等，每种字母恰好抵消
- 赎金信：magazine 可以比 ransomNote 长，只要需求 ≤ 供给

## 代码

```java
public boolean canConstruct(String ransomNote, String magazine) {
    int[] count = new int[26];

    // 第一步：统计 magazine 中的字母（供货）
    for (int i = 0; i < magazine.length(); i++) {
        count[magazine.charAt(i) - 'a']++;
    }

    // 第二步：消耗 ransomNote 中的字母（需求）
    for (int i = 0; i < ransomNote.length(); i++) {
        count[ransomNote.charAt(i) - 'a']--;
    }

    // 第三步：检查是否有字母库存不足
    for (int i = 0; i < 26; i++) {
        if (count[i] < 0) return false;
    }

    return true;
}
```

---

## 关键点

1. `int[26]` 数组模拟 HashMap，下标 = `c - 'a'`（0~25 对应 a~z）
2. 两个循环分开写，不能合在一起（两个字符串长度可能不同）
3. 检查范围是 0~25（26 个字母），不是数组长度
4. `< 0` 而不是 `!= 0`，因为供货可以多于需求

## 易错总结（真实踩坑记录）

```java
// ❌ 错误 1：逻辑反了

// ❌ 错误 2：两个串放一个循环（长度不同会越界）
for (int i = 0; i < magazine.length(); i++) {
    count[magazine.charAt(i) - 'a']++;
    count[ransomNote.charAt(i) - 'a']--;  // 如果 ransomNote 更短？更长？
}

// ❌ 错误 3：检查范围写成字符串长度
```
