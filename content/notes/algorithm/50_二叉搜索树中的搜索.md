# 二叉搜索树中的搜索（LeetCode 700）

## 题目
在二叉搜索树（BST）中查找值为 val 的节点，返回该节点（及其子树），不存在返回 null。

```
        5
       / \
      3   8
     / \   \
    2   4   9

searchBST(root, 4) → 节点 4
```

## 前置知识：二叉搜索树（BST）
BST 的核心性质——**左小右大**，对每棵子树都成立：
```
左子树所有节点 < 根节点 < 右子树所有节点
```
这个性质使搜索时每次比较都能排除一半，类似二分查找。

## 核心思想
利用 BST 左小右大的性质，沿一条路径向下搜索。比较当前节点值和目标值：
- `val < root.val` → 往左走
- `val > root.val` → 往右走
- `val == root.val` → 找到，返回

## 关键步骤
1. 空节点 → 返回 null
2. val 小于当前值 → 递归搜索左子树
3. val 大于当前值 → 递归搜索右子树
4. 相等 → 返回当前节点

## 时空复杂度

| 项目 | 复杂度 | 推导 |
|------|--------|------|
| 时间 | O(h) | h = 树高，平衡时 O(log n)，退化为 O(n) |
| 空间（递归） | O(h) | 递归栈深度 |
| 空间（迭代） | O(1) | 只用了一个指针 |

## 模式归类：BST-路径搜索（比较定向 + 无回溯）

## Java 代码

### 递归法
```java
public TreeNode searchBST(TreeNode root, int val) {
    if (root == null) return null;

    if (root.val > val) {
        return searchBST(root.left, val);
    } else if (root.val < val) {
        return searchBST(root.right, val);
    } else {
        return root;
    }
}
```

### 迭代法（推荐，BST 搜索不需要回溯）
```java
public TreeNode searchBST(TreeNode root, int val) {
    while (root != null) {
        if (root.val > val) {
            root = root.left;
        } else if (root.val < val) {
            root = root.right;
        } else {
            return root;
        }
    }
    return null;
}
```

## 易错点
1. ⚠️ 不额外需要 result 变量——每个分支直接 return，简洁且不会漏
2. BST 搜索是一条路径走到底，没有回溯需求，迭代法更优
3. 树退化为链表时时间复杂度 O(n)
