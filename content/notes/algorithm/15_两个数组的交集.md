# 两个数组的交集 — 学习笔记

- **日期：** 2026-07-17
- **题目：** [349. Intersection of Two Arrays](https://leetcode.cn/problems/intersection-of-two-arrays/)
- **难度：** 简单
- **模式归类：** 哈希表-HashSet
- **题解：** [B站视频](https://www.bilibili.com/video/BV1ba411S7wu/)

---

## 核心思想

nums1 倒进 HashSet（去重 + O(1) 查找），遍历 nums2 检查是否存在。

> 类比：把第一盒的糖倒进罐子里，从第二盒拿糖看罐子里有没有。

---

## 关键步骤

1. nums1 全部 `.add()` 进 set1
2. 遍历 nums2，`set1.contains(x)` 为 true 的加入结果
3. 同时 `set1.remove(x)` 防止重复计入

---

## 时空复杂度

| 复杂度 | 值 |
|--------|----|
| 时间 | O(n+m) — 两个数组各遍历一遍 |
| 空间 | O(n) — set1 存 nums1 的元素 |

---

## Java 代码

```java
import java.util.*;

class Solution {
    public int[] intersection(int[] nums1, int[] nums2) {
        HashSet<Integer> set1 = new HashSet<>();
        HashSet<Integer> res = new HashSet<>();
        
        for (int x : nums1) set1.add(x);         // 倒进箱子
        for (int x : nums2) {
            if (set1.contains(x)) res.add(x);     // 找到了
        }
        
        // HashSet → int[]
        int[] ans = new int[res.size()];
        int i = 0;
        for (int x : res) ans[i++] = x;
        return ans;
    }
}
```

---

## 为什么用两个 Set

- set1：存 nums1 的元素，提供 O(1) 查找
- res：存交集结果，天然去重（比如 nums2 出现多次 2，res 只记一次）
