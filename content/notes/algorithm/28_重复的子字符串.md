# 重复的子字符串 — 学习笔记

- **日期：** 2026-07-20
- **题目：** [459. Repeated Substring Pattern](https://leetcode.cn/problems/repeated-substring-pattern/)
- **难度：** 简单
- **模式归类：** 字符串技巧（拼接 + 掐头去尾）
- **题解：** [B站视频](https://www.bilibili.com/video/BV1cg41127fw/)

---

## 核心思想

```
如果 s 可以完全由子串重复构成：
  把两个 s 拼起来 → 掐头去尾 → 中间一定还包含 s
```

---

## 图解

```
s = "abab"

s + s           = "abababab"
掐头去尾         → "bababa"
"bababa" 包含 "abab" ? → ✅ true
```

```
s = "aba"

s + s           = "abaaba"
掐头去尾         → "baab"
"baab" 包含 "aba" ? → ❌ false
```

---

## 代码

```java
class Solution {
    public boolean repeatedSubstringPattern(String s) {
        String doubled = s + s;
        String trimmed = doubled.substring(1, doubled.length() - 1);
        return trimmed.contains(s);
    }
}
```

---

## 关键点

1. `s + s` — 拼两个，周期自然出现
2. `substring(1, len-1)` — 掐头去尾，去掉保护边界
3. `contains(s)` — 本质就是调用 strStr（上一道题）
4. 也可以不用 `contains`，直接用上一道题的 `strStr(trimmed, s)` 手动匹配
5. 时间复杂度 O(n)，空间 O(n)
