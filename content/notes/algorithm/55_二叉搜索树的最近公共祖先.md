## 题目
给一棵**二叉搜索树**和两个节点 p、q，返回最近公共祖先。p、q 一定在树里。

## 和 54 题（普通二叉树 LCA）的区别
| | 54 普通二叉树 | 55 BST |
|---|---|---|
| 怎么知道 p、q 在哪 | 遍历整棵树（后序） | 值比较一次判断 |
| 时间复杂度 | O(n) | **O(h)**（树高） |
| 代码 | 三态上传，十几行 | 4 行递归 |
| 关键前提 | 无 | **左小右大** |

## 核心思想
站在一个节点上，利用 BST 性质（左小右大）判断 p、q 的走向：

| 关系 | 结论 |
|------|------|
| p、q 都 < root.val | 都在左子树 → 往左走 |
| p、q 都 > root.val | 都在右子树 → 往右走 |
| **分居两侧**（一左一右） | root 就是 LCA，停 |
| **命中**（root 就是 p 或 q） | root 就是 LCA，停 |

## 为什么不用遍历整棵树
BST 性质保证：`p.val < root.val` → p 必在左子树（不需要真的去找）。
所以「分居两侧」时，值比较已经证明了 p、q 各在一侧，root 必是分岔点。
**不看子树，只看值**。

## 示例
```
       6
      / \
     2   8
    / \  / \
   0  4 7   9
      / \
     3   5
```
- p=0, q=5 → 都 < 6 往左 → 2：0<2、5>2 分居 → 返回 **2**
- p=2, q=4 → 都 < 6 往左 → 2：命中 p → 返回 **2**
- p=2, q=8 → 分居两侧 → 返回 **6**
- 全程 O(h)，只走了根到答案这一条路径

## Java 代码（递归版，4 行）
```java
class Solution {
    public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
        if (p.val < root.val && q.val < root.val) return lowestCommonAncestor(root.left, p, q);
        if (p.val > root.val && q.val > root.val) return lowestCommonAncestor(root.right, p, q);
        return root;   // 分居两侧 或 命中 → 自己就是 LCA
    }
}
```

## Java 代码（迭代版，O(1) 空间）
```java
class Solution {
    public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
        TreeNode cur = root;
        while (true) {
            if (p.val < cur.val && q.val < cur.val) cur = cur.left;
            else if (p.val > cur.val && q.val > cur.val) cur = cur.right;
            else return cur;
        }
    }
}
```

## 复杂度
- 时间 O(h)：走一条路径，h 是树高（平均 log n，最坏 n 链式）
- 空间 O(1)（迭代版）；递归版 O(h) 栈

## 易错点
1. **值比较**：`p.val < cur.val`，不是节点引用比较（这题按值定向）
2. 迭代版必须**更新 cur**（`cur = cur.left`），否则死循环
3. while 循环里所有分支都 return → 循环是死的，应去掉（递归版）
4. 别把 54 题的「看子树」思维带进来——BST 版只看值，不看子树
5. 最后一行 `return root` 覆盖「分居两侧」和「命中」两种情况，
   顺序上放在最后就是正确的（前两行已经处理了同侧的情况）
