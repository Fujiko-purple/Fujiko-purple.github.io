# 删除链表的倒数第 N 个节点 — 学习笔记

- **日期：** 2026-07-16
- **题目：** [19. Remove Nth Node From End of List](https://leetcode.cn/problems/remove-nth-node-from-end-of-list/)
- **难度：** 中等
- **模式归类：** 链表-快慢指针
- **题解：** [B站视频](https://www.bilibili.com/video/BV1vW4y1U7Gf/)

---

## 核心思想

快慢指针 + dummy。fast 先走 n 步，然后 fast 和 slow 一起走。fast 到末尾时，slow 正好停在要删节点的前一个位置。

> 类比：你和朋友赛跑，你让朋友先跑 10 米，然后同时跑。你到终点时，朋友正好落后你 10 米——他所在的位置就是倒数第 10 米。

---

## 关键步骤

1. `dummy` 虚拟头节点，`slow = fast = dummy`
2. fast 先走 n 步
3. fast 和 slow 一起走，直到 fast.next == null
4. `slow.next = slow.next.next` 删除目标节点
5. 返回 `dummy.next`

---

## Java 代码

```java
class Solution {
    public ListNode removeNthFromEnd(ListNode head, int n) {
        ListNode dummy = new ListNode(0, head);
        ListNode fast = dummy;
        ListNode slow = dummy;
        
        // fast 先走 n 步
        for (int i = 0; i < n; i++) {
            fast = fast.next;
        }
        
        // 一起走
        while (fast.next != null) {
            slow = slow.next;
            fast = fast.next;
        }
        
        // 删除 slow.next
        slow.next = slow.next.next;
        return dummy.next;
    }
}
```
