- **模式归类：** BST-反序中序后缀和

## 题目

给出二叉搜索树的根节点 `root`，该树的节点值各不相同，请你将其转换为累加树（Greater Sum Tree），使每个节点 `node` 的新值等于原树中大于或等于 `node.val` 的值之和。返回转换后的二叉搜索树的根节点。

## 核心思想（一句话）

每个节点新值 = 原树中**所有值 ≥ 自己的节点之和**；BST 中序 = 升序 → 这就是中序序列的**后缀和**，反序中序遍历一路累加即可。

## 关键洞察

1. **定义看值不看位置**：5 的新值 = 5+6+7+8 = 26——比它大的值散落在树各处（右子树、右上方），累加树不管左右子树，只管值的大小
2. **BST 中序 = 升序**：0,1,2,3,4,5,6,7,8 → "值 ≥ 自己" = 中序序列里自己及右侧所有值（后缀和）
3. **反序中序（右-根-左）自然按值从大到小访问** → 一路累计前缀 sum

## 树图示例（官方示例）

```
原树：                        累加树：
        4                         30
      /   \                     /    \
     1     6                   36    21
    / \   / \                 /  \   / \
   0   2 5   7               36  35 26 15
        \     \                   \     \
         3     8                   33    8
```

### 反序中序累加过程

| 访问序 | 节点 | sum 变化 | 新值 |
|:--:|:--:|------|:--:|
| 1 | 8 | 0+8=8 | 8 |
| 2 | 7 | 8+7=15 | 15 |
| 3 | 6 | 15+6=21 | 21 |
| 4 | 5 | 21+5=26 | 26 |
| 5 | 4 | 26+4=30 | 30 |
| 6 | 3 | 30+3=33 | 33 |
| 7 | 2 | 33+2=35 | 35 |
| 8 | 1 | 35+1=36 | 36 |
| 9 | 0 | 36+0=36 | 36 |

## 关键步骤

1. `dfs(node.right)` —— 先走右子树（最大的值最先访问）
2. `sum += node.val` —— 把当前值加进累计
3. `node.val = sum` —— 换成累计值（后缀和）
4. `dfs(node.left)` —— 再走左子树

## 易错点

- **sum 必须是成员变量**：递归参数会为每个分支创建副本，子调用里的修改回不到父调用；成员变量所有递归共享同一个，才能持续累计
- 遍历顺序是右-根-左，不是左-根-右（那是升序，要降序访问才能累加）
- 原地修改：不新建树，直接改 node.val 返回原根

## 复杂度

- 时间：O(n)（每个节点访问一次）
- 空间：O(h)（递归栈）

## 最终代码

```java
class Solution {
    int sum = 0;   // 累计值：所有已访问（更大）节点之和——成员变量，跨递归共享

    public TreeNode convertBST(TreeNode root) {
        dfs(root);
        return root;
    }

    void dfs(TreeNode node) {
        if (node == null) return;
        dfs(node.right);        // ① 先走右子树：从最大的值开始
        sum += node.val;        // ② 累加
        node.val = sum;         // ③ 换成累加值（后缀和）
        dfs(node.left);         // ④ 再走左子树
    }
}
```
