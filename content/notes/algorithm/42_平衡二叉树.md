# 平衡二叉树（LeetCode 110）

## 题目
给定一棵二叉树，判断它是否是高度平衡的，即任意节点的左右子树高度差不超过 1。

## 核心思想
递归求高度的同时判断平衡。用 -1 作为"不平衡"的哨兵信号，正常高度为非负数。

## 关键步骤
1. 空节点 → 返回高度 0（平衡）
2. 递归求左子树高度，如果返回 -1（不平衡）→ 直接上报 -1
3. 递归求右子树高度，如果返回 -1（不平衡）→ 直接上报 -1
4. 左右高度差 > 1 → 当前节点不平衡，返回 -1
5. 否则返回 `max(左,右) + 1`（正常高度）

## 时空复杂度

| 项目 | 复杂度 | 推导 |
|------|--------|------|
| 时间 | O(n) | 每个节点访问一次 |
| 空间 | O(h) | 递归栈深度 |

## 模式归类：二叉树-平衡判断（哨兵值）

## Java 代码

```java
public boolean isBalanced(TreeNode root) {
    // height() 返回 -1 说明不平衡
    int h = height(root);
    if (h == -1) {
        return false;
    } else {
        return true;
    }
}

int height(TreeNode root) {
    if (root == null) {
        return 0;
    }

    int leftH = height(root.left);
    if (leftH == -1) {
        return -1;  // 左子树不平衡，上报
    }

    int rightH = height(root.right);
    if (rightH == -1) {
        return -1;  // 右子树不平衡，上报
    }

    if (Math.abs(leftH - rightH) > 1) {
        return -1;  // 当前节点不平衡
    }

    return Math.max(leftH, rightH) + 1;
}
```

## 易错点
1. -1 是哨兵值，不能写成 null（int 类型不能为 null）
2. 左右子树有一个不平衡就要立即返回，不要再递归另一边
3. 主函数要对 -1 做翻译，不能直接把 height() 的结果当 boolean 用
