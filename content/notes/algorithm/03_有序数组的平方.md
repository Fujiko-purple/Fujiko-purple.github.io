# 有序数组的平方 — 学习笔记

- **日期：** 2026-07-14
- **题目：** [977. Squares of a Sorted Array](https://leetcode.cn/problems/squares-of-a-sorted-array/)
- **难度：** 简单
- **模式归类：** 双指针-两端指针（相向指针）
- **题解：** [B站视频](https://www.bilibili.com/video/BV1QB4y1D7ep/)

---

## 核心思想

排序数组的平方呈 **V 字形**（y = x²）：两端大、中间小。最大值一定出现在当前剩余元素的最左或最右。

> 类比：抛物线两端的人比身高，谁高谁先出列，站到新队伍最后面。两边的人逐步向中间靠拢。

---

## 关键步骤

1. `left = 0`, `right = nums.length - 1`, `pos = nums.length - 1`
2. 新数组 `result`，从末尾向前填入
3. 循环 `while (left <= right)`：
   - `left² > right²` → `result[pos] = left²`, `left++`
   - 否则 → `result[pos] = right²`, `right--`
   - `pos--`
4. 返回 `result`

---

## 时空复杂度

| 复杂度 | 值 | 推导 |
|--------|-----|------|
| 时间 | O(n) | 每个元素只看一次 |
| 空间 | O(n) | 新建了一个等长数组（必须的，没办法原地） |

---

## 为什么必须是新数组（不能原地）

平方后元素位置会发生交错，原地操作会覆盖还没用到的值。这题 O(n) 空间是必须付出的代价。

---

## 易错点

1. **比的是平方值，不是原值** — `nums[left] * nums[left]` vs `nums[right] * nums[right]`
2. **逆序填入** — result 从 pos=n-1 开始递减，因为每次取的是最大值
3. **left==right 时还要处理** — 循环条件用 `<=`，最后一个元素也要填入
4. **⚠️ 谁被取走谁动（最常犯的错）**
   - `left` 平方大 → 取走 `left` → **`left++`**（不是 right--）
   - `right` 平方大 → 取走 `right` → **`right--`**（不是 left++）
   - 记忆：**"谁赢了谁走"**

---

## Java 代码

```java
class Solution {
    public int[] sortedSquares(int[] nums) {
        int n = nums.length;
        int[] result = new int[n];
        int left = 0, right = n - 1;
        int pos = n - 1;
        while (left <= right) {
            int leftSquare = nums[left] * nums[left];
            int rightSquare = nums[right] * nums[right];
            if (leftSquare > rightSquare) {
                result[pos] = leftSquare;
                left++;
            } else {
                result[pos] = rightSquare;
                right--;
            }
            pos--;
        }
        return result;
    }
}
```

## 与 #2 移除元素的对比

| | #2 移除元素 | #3 有序数组平方 |
|------|------|------|
| 指针方向 | 同向（fast 前、slow 后） | 相向（left→ ←right） |
| 指针关系 | fast >= slow | left <= right |
| 操作 | 覆盖原数组 | 填入新数组 |
| 空间 | O(1) | O(n) |
