## 核心思想

链表的"删除"就是让前驱节点的 `next` 绳子跳过要删的节点。加一个虚拟头节点（dummy）让头节点也能统一处理。

> 类比：排队时有人要离队，前面的人拉一下后面人的手，绕过这个人。

---

## 关键步骤

1. 创建 `dummy`，`dummy.next = head`
2. `curr` 从 dummy 开始向后遍历
3. 每次检查 `curr.next`：
   - `curr.next.val == val` → 跳过：`curr.next = curr.next.next`
   - 否则 → `curr = curr.next`
4. 返回 `dummy.next`（因为 head 可能已被删）

---

## 时空复杂度

| 复杂度 | 值 |
|--------|----|
| 时间 | O(n) — 遍历一遍 |
| 空间 | O(1) — 只多了 dummy 和 curr |

---

## 易错点

1. **删除后不要移动 curr** — 因为新的 `curr.next` 还没检查
2. **返回 `dummy.next` 不是 `head`** — head 可能已被删
3. **`curr.next` 可能是 null** — 循环条件必须检查

---

## Java 代码

```java
class Solution {
    public ListNode removeElements(ListNode head, int val) {
        ListNode dummy = new ListNode(0, head);  // 虚拟头节点
        ListNode curr = dummy;
        while (curr.next != null) {
            if (curr.next.val == val) {
                curr.next = curr.next.next;      // 跳过要删的
            } else {
                curr = curr.next;                // 继续往后
            }
        }
        return dummy.next;
    }
}
```

---

## 与数组"移除元素"的对比

| | 数组 | 链表 |
|------|------|------|
| 删除方式 | `nums[slow] = nums[fast]` 覆盖 | `curr.next = curr.next.next` 跳绳子 |
| 遍历方式 | fast 逐个扫描 | `curr = curr.next` 顺绳摸 |
| 处理头元素 | 天然统一 | 需要 dummy 统一 |
| 空间 | O(1) | O(1) |
