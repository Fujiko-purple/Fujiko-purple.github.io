# 螺旋矩阵 II — 学习笔记

- **日期：** 2026-07-15
- **题目：** [59. Spiral Matrix II](https://leetcode.cn/problems/spiral-matrix-ii/)
- **难度：** 中等
- **模式归类：** 矩阵模拟
- **题解：** [B站视频](https://www.bilibili.com/video/BV1SL4y1N7mV/)

---

## 核心思想

定四条边界（top / bottom / left / right），按"右→下→左→上"的顺序填入数字，每走完一条边就缩一格边界，一圈一圈往里转。

> 类比：剥洋葱，一圈一层皮，剥完一层往里走一层。或者操场跑圈，每跑完一圈跑道缩进一格。

---

## 关键步骤

```
初始化：top=0, bottom=n-1, left=0, right=n-1, num=1

while (num <= n*n):
  ① 从左到右填充 top 行 → top++（上边界下移）
  ② 从上到下填充 right 列 → right--（右边界左移）
  ③ 从右到左填充 bottom 行 → bottom--（下边界上移）
  ④ 从下到上填充 left 列 → left++（左边界右移）
```

---

## 四个 for 循环与坐标的关系

| 方向 | 固定的是 | 变化的是 | for 循环 |
|------|---------|---------|---------|
| → 右 | 行 = top | 列 j：left → right | `for(j=left; j<=right; j++) matrix[top][j]=num++` |
| ↓ 下 | 列 = right | 行 i：top → bottom | `for(i=top; i<=bottom; i++) matrix[i][right]=num++` |
| ← 左 | 行 = bottom | 列 j：right → left | `for(j=right; j>=left; j--) matrix[bottom][j]=num++` |
| ↑ 上 | 列 = left | 行 i：bottom → top | `for(i=bottom; i>=top; i--) matrix[i][left]=num++` |

---

## 时空复杂度

| 复杂度 | 值 |
|--------|----|
| 时间 | O(n²) — 每个格子填一次 |
| 空间 | O(n²) — 结果矩阵（不算额外开销） |

---

## 易错点

1. **循环变量不要用 i 充当所有** — 行用 i，列用 j，看清谁固定谁变
2. **→和↓的循环条件用 `<=`，←和↑用 `>=`** — 因为方向变了
3. **边界更新在每条边之后** — 顺序不能乱：右上边界先缩，左下边界后缩

---

## Java 代码

```java
class Solution {
    public int[][] generateMatrix(int n) {
        int[][] matrix = new int[n][n];
        int top = 0, bottom = n - 1;
        int left = 0, right = n - 1;
        int num = 1;
        
        while (num <= n * n) {
            // ① → 右：top 行，列从左到右
            for (int j = left; j <= right; j++) {
                matrix[top][j] = num++;
            }
            top++;
            
            // ② ↓ 下：right 列，行从上到下
            for (int i = top; i <= bottom; i++) {
                matrix[i][right] = num++;
            }
            right--;
            
            // ③ ← 左：bottom 行，列从右到左
            for (int j = right; j >= left; j--) {
                matrix[bottom][j] = num++;
            }
            bottom--;
            
            // ④ ↑ 上：left 列，行从下到上
            for (int i = bottom; i >= top; i--) {
                matrix[i][left] = num++;
            }
            left++;
        }
        
        return matrix;
    }
}
```
