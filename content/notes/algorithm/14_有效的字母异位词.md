## 核心思想

用 `int[26]` 数组模拟字母表。s 的字母做加法，t 的字母做减法。最后全为 0 就是异位词。

> 类比：两袋字母，往同一个 26 格的格子里放——第一袋每个字母 +1，第二袋每个字母 -1。最后所有格子归零，说明两袋字母组成一样。

---

## 关键步骤

1. `int[26] count` 计数器数组
2. 遍历 s：`count[c - 'a']++`（字母 → 下标 0~25）
3. 遍历 t：`count[c - 'a']--`
4. 检查 count 是否全为 0

---

## 时空复杂度

| 复杂度 | 值 |
|--------|----|
| 时间 | O(n) |
| 空间 | O(1) — 固定 26 格 |

---

## Java 代码

```java
class Solution {
    public boolean isAnagram(String s, String t) {
        if (s.length() != t.length()) return false;
        
        int[] count = new int[26];
        for (int i = 0; i < s.length(); i++) {
            count[s.charAt(i) - 'a']++;
            count[t.charAt(i) - 'a']--;
        }
        
        for (int n : count) {
            if (n != 0) return false;
        }
        return true;
    }
}
```

---

## 巧妙优化

上面一次循环同时处理 s 和 t，省掉一个循环。
