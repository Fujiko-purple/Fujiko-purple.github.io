# 四数之和 — 学习笔记

- **日期：** 2026-07-18
- **题目：** [18. 4Sum](https://leetcode.cn/problems/4sum/)
- **难度：** 中等
- **模式归类：** 双指针-两端指针（固定两个数，化归三数之和）
- **题解：** [B站视频](https://www.bilibili.com/video/BV1DS4y1o7gJ/)

---

## 核心思想

**三数之和的扩展：固定 a + 固定 b + 双指针找 c、d**

```
四数之和：a + b + c + d = target
    ↓
    c + d = target - a - b
    ↓
固定 a、b，在右边用双指针找 c + d = target - a - b
```

跟三数之和对比：

| | 三数之和 | 四数之和 |
|------|------|------|
| 固定 | 1 个数 (a) | 2 个数 (a, b) |
| 双指针 | left, right 找 b, c | left, right 找 c, d |
| 目标 | -a | target - a - b |
| 循环层数 | 1 层外层 | 2 层外层 |

---

## 代码

```java
public List<List<Integer>> fourSum(int[] nums, int target) {
    List<List<Integer>> result = new ArrayList<>();
    Arrays.sort(nums);                                        // 1. 排序

    for (int i = 0; i < nums.length; i++) {                   // 2. 固定 a
        if (i > 0 && nums[i] == nums[i - 1]) continue;        // 去重 a

        for (int j = i + 1; j < nums.length; j++) {           // 3. 固定 b
            if (j > i + 1 && nums[j] == nums[j - 1]) continue; // 去重 b

            int left = j + 1, right = nums.length - 1;
            while (left < right) {                            // 4. 双指针
                int sum = nums[i] + nums[j] + nums[left] + nums[right];

                if (sum < target) left++;
                else if (sum > target) right--;
                else {
                    result.add(Arrays.asList(nums[i], nums[j], nums[left], nums[right]));
                    while (left < right && nums[left] == nums[left + 1]) left++;   // 去重 c
                    while (left < right && nums[right] == nums[right - 1]) right--; // 去重 d
                    left++; right--;
                }
            }
        }
    }
    return result;
}
```

---

## 关键点

1. **两层固定 + 一层双指针** — 比三数之和多了一轮 for
2. **去重分四层** — a 的重复、b 的重复、c 的重复、d 的重复
3. **目标不再固定是 0** — 是 `target - a - b`
4. **剪枝可跳过** — 本题不用剪枝也不会超时，先写对再说
5. 时间复杂度 O(n³) — 比三数之和 O(n²) 多一层
6. **⚠️ int 溢出** — 四个 10⁹ 级别的数相加会超出 int 上限（≈21 亿），sum 要用 `long`：

```java
// ❌ 可能溢出
int sum = nums[i] + nums[j] + nums[left] + nums[right];

// ✅ 安全
long sum = (long) nums[i] + nums[j] + nums[left] + nums[right];
```

只需要在第一个数前加 `(long)`，Java 会自动把后面的提升为 long 运算。
