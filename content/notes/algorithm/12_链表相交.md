# 链表相交 — 学习笔记

- **日期：** 2026-07-16
- **题目：** 面试题 02.07. 链表相交
- **难度：** 简单
- **模式归类：** 链表-双指针
- **题解：** 无

---

## 核心思想

先算两个链表长度差，长的先走 gap 步对齐，然后一起走，第一个相同的节点就是交点。

> 类比：两条长短不一的路汇入同一条路。让走长路的人先出发，走到两条路剩下距离相同时，两人一起走——碰头的地方就是汇合点。

---

## 关键步骤

1. 分别遍历 A 和 B，算出长度 lenA、lenB
2. 算出差距 gap = |lenA - lenB|
3. 长的链表头指针先走 gap 步
4. 两个指针一起走，每次比较指针是否相等（==，不是 val 相等）
5. 相等 → 返回交点；都走到 null → 无相交

---

## ⚠️ 关键：比的是节点引用（地址），不是值

```java
if (curA == curB)  // ✅ 真正的同一节点
if (curA.val == curB.val)  // ❌ 只是值相等，节点可能不同
```

---

## Java 代码

```java
public class Solution {
    public ListNode getIntersectionNode(ListNode headA, ListNode headB) {
        ListNode curA = headA, curB = headB;
        int lenA = 0, lenB = 0;
        
        // 1. 算长度
        while (curA != null) { lenA++; curA = curA.next; }
        while (curB != null) { lenB++; curB = curB.next; }
        
        // 2. 重新指向头部
        curA = headA;
        curB = headB;
        
        // 3. 长的先走 gap 步
        int gap = Math.abs(lenA - lenB);
        if (lenA > lenB) {
            for (int i = 0; i < gap; i++) curA = curA.next;
        } else {
            for (int i = 0; i < gap; i++) curB = curB.next;
        }
        
        // 4. 一起走找交点
        while (curA != curB) {
            curA = curA.next;
            curB = curB.next;
        }
        return curA;  // 无相交时 curA == null
    }
}
```

## 与删除倒数第 N 个节点的联系

| | 删除倒数第N个 | 链表相交 |
|------|------------|---------|
| 模式 | 快慢指针 | 快慢指针 |
| N 怎么来 | 题目给定 | 先算长度差 |
| 快指针先走 | n 步 | gap 步 |
| 终止条件 | fast.next == null | curA == curB |
