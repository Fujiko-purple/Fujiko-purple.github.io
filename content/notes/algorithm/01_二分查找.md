## 核心思想

在**有序数组**中，每次取中间值比较，根据大小关系砍掉一半搜索范围，不断重复直到找到目标或范围为空。

> 类比：翻字典查单词——翻到中间，看字母顺序决定往前翻还是往后翻，每次扔掉一半。

---

## 关键步骤

1. `left = 0`, `right = nums.length - 1`
2. 循环条件：`while (left <= right)`
3. `mid = left + (right - left) / 2`（防溢出写法）
4. 比较 `nums[mid]` 与 `target`：
   - `nums[mid] == target` → 找到，返回 `mid`
   - `nums[mid] < target` → 目标在右边，`left = mid + 1`
   - `nums[mid] > target` → 目标在左边，`right = mid - 1`
5. 循环结束仍未找到 → 返回 `-1`

---

## 时空复杂度

| 复杂度 | 值 | 推导 |
|--------|-----|------|
| 时间 | O(log n) | 每次砍半，最多砍 log₂n 次 |
| 空间 | O(1) | 只用了 left/right/mid 三个变量 |

---

## 易错点（避坑）

1. **循环条件**：`left <= right` 还是 `left < right`？
   - 闭区间 `[left, right]` → `<=`（当 left==right 时区间还有一个元素要检查）

2. **mid 计算**：`(left + right) / 2` 在 left+right 很大时会**溢出**
   - Java 中 int 最大约 21 亿，left+right 超过就变负数
   - 安全写法：`left + (right - left) / 2`

3. **边界更新**：`left = mid + 1` 不是 `left = mid`
   - 如果写成 `left = mid`，当 target 在右边时可能死循环

---

## 边界条件 CheckList

- [x] 空数组 → 直接返回 `-1`
- [x] target 比最小值还小 → left 不变，right 最终 < left
- [x] target 比最大值还大 → right 不变，left 最终 > right
- [x] 重复元素 → 返回任意一个位置即可（这题不要求最左/最右）

---

## Java 标准代码

```java
class Solution {
    public int search(int[] nums, int target) {
        int left = 0;
        int right = nums.length - 1;
        while (left <= right) {
            int mid = left + (right - left) / 2;  // 防溢出
            if (nums[mid] == target) {
                return mid;
            } else if (nums[mid] < target) {
                left = mid + 1;
            } else {
                right = mid - 1;
            }
        }
        return -1;
    }
}
```
