## 题目

给你一个**无重复元素**的整数数组 `candidates` 和一个目标整数 `target`，找出所有可以使数字和为目标数 `target` 的组合。`candidates` 中的**每个数字可以被无限次重复选取**。

**示例**：`candidates=[2,3,5]`，target=8 → `[[2,2,2,2],[2,3,3],[3,5]]`

## 核心思想（一句话）

**把 61 的 `i+1` 改成 `i`**：`i+1` 禁止重复，`i` 允许重复——且"起点原地或往后"依然挡住排列乱序（`[3,2]` 不会出现）。

## 关键区别：`i` 还是 `i+1`？

用"排队"理解：`candidates=[2,3,5]` 是一支队伍，`i` 是当前下标。

| | 下一层起点 | 效果 |
|--|:--:|------|
| 61 组合 | `i + 1` | 选完往前挪一位 → 每个数最多用一次 |
| 64 组合总和 | **`i`** | 选完**原地不动** → 还能再选自己；但只能原地或往后，**不回头** |

**"原地"保留重复能力，"不回头"挡住 `[3,2]`**——这两件事 `i` 同时做到。

## 关键步骤

```
backtrack(candidates, target, 0, 0, path)   // 起手 startIndex=0, sum=0

if (sum > target) return;               // 剪枝：和超了
if (sum == target) {                    // 命中
    res.add(new ArrayList<>(path));
    return;
}
for (int i = startIndex; i < candidates.length; i++) {
    path.add(candidates[i]);
    backtrack(candidates, target, i, sum + candidates[i], path);   // 关键：传 i，不是 i+1
    path.remove(path.size() - 1);
}
```

## 示例手算（[2,3,5]，target=8）

```
[2] → [2,2] → [2,2,2] → [2,2,2,2] ✅ sum=8 收获
     [2,2,3] → sum=7 → 加3=10剪 → 加5剪
     [2,2,2] 再往下都超，剪
[2,3] → [2,3,3] ✅ sum=8 收获（第三次起点 i=1，原地可选3）
[3] → [3,5] ✅ sum=8 收获
[5] → 无法凑到8（5+5=10剪）
结果：[[2,2,2,2],[2,3,3],[3,5]]
```

## 易错点

1. **下一层必须传 `i` 不是 `i+1`**——传 `i+1` 就回到"禁重复"，`[2,2,2,2]` 永远组不出来
2. 终止条件 `sum > target` 剪枝别忘了（候选是正数，加下去只会更大）
3. `candidates` 无重复是前提；若有重复需要先排序+去重（另一道题）
4. `sum == target` 后**必须 return**，不能继续往下加（否则超 target）

## 时空复杂度

| 项目 | 复杂度 | 推导 |
|------|--------|------|
| 时间 | O(S) | S = 所有可行组合的长度和（正数候选，树有限） |
| 空间 | O(target/最小值) | 递归深度 ≤ target / min(candidates) |

## Java 代码

```java
class Solution {
    List<List<Integer>> res = new ArrayList<>();

    public List<List<Integer>> combinationSum(int[] candidates, int target) {
        backtrack(candidates, target, 0, 0, new ArrayList<>());
        return res;
    }

    void backtrack(int[] candidates, int target, int startIndex, int sum, List<Integer> path) {
        if (sum > target) return;                     // 剪枝
        if (sum == target) {                          // 命中
            res.add(new ArrayList<>(path));
            return;
        }
        for (int i = startIndex; i < candidates.length; i++) {
            path.add(candidates[i]);
            backtrack(candidates, target, i, sum + candidates[i], path);   // i 允许重复
            path.remove(path.size() - 1);
        }
    }
}
```

## 一句话应用场景

凑金额/凑零钱：面值数组里可以重复拿，正好凑到目标——自动贩卖机找零、配餐凑满减。
