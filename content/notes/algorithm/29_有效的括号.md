# 有效的括号 — 学习笔记

- **日期：** 2026-07-23
- **题目：** [20. Valid Parentheses](https://leetcode.cn/problems/valid-parentheses/description/)
- **难度：** 简单
- **模式归类：** 栈（括号匹配）
- **题解：** [B站视频](https://www.bilibili.com/video/BV1AF411w78g/)

## 核心思想

```
遇到左括号 → push 到栈里（等配对）
遇到右括号 → 看栈顶是不是配对的左括号
  是 → pop 消掉
  不是 → 直接 false
最后栈空了才算全匹配
```

---

## 图解

```
s = "{ [ ] }"

① { → push      栈: [{]
② [ → push      栈: [{, []
③ ] → 右括号，栈顶 [ 配对 ✓ pop → 栈: [{]
④ } → 右括号，栈顶 { 配对 ✓ pop → 栈: []
栈空 ✅ true
```

```
s = "( ]"

① ( → push      栈: [(]
② ] → 右括号，栈顶 ( 不配 ✗ → ❌ false
```

## 代码

```java
class Solution {
    public boolean isValid(String s) {
        // 剪枝：奇数长度肯定不行
        if (s.length() % 2 != 0) return false;

        Deque<Character> stack = new ArrayDeque<>();
        // 映射：右括号 → 左括号
        HashMap<Character, Character> map = new HashMap<>();
        map.put(')', '(');
        map.put(']', '[');
        map.put('}', '{');

        for (char c : s.toCharArray()) {
            if (map.containsKey(c)) {
                // 是右括号
                if (stack.isEmpty() || stack.peek() != map.get(c)) {
                    return false;
                }
                stack.pop();
            } else {
                // 是左括号
                stack.push(c);
            }
        }
        return stack.isEmpty();
    }
}
```

---

### 方案 B（反向映射，更简洁）

```java
class Solution {
    public boolean isValid(String s) {
        if (s.length() % 2 != 0) return false;

        Deque<Character> stack = new ArrayDeque<>();
        for (char c : s.toCharArray()) {
            // 左括号 → 把对应的右括号 push 进去
            if (c == '(') stack.push(')');
            else if (c == '[') stack.push(']');
            else if (c == '{') stack.push('}');
            // 右括号 → 直接跟栈顶比
            else if (stack.isEmpty() || stack.pop() != c) return false;
        }
        return stack.isEmpty();
    }
}
```

> 方案 B 省掉了 HashMap，右括号来了直接 pop 比，逻辑更直。

---

## 关键点

1. **剪枝** — 奇数长度直接 false，省去不必要的遍历
2. **右括号映射左括号** — 用 HashMap 存 `) → (` 三个映射，省去三个 if
3. **判空** — 遇到右括号时栈为空说明没有左括号等它，直接 false
4. **最后判空** — 遍历完栈不为空说明有左括号没配上，false
5. 时间复杂度 O(n)，空间复杂度 O(n)
