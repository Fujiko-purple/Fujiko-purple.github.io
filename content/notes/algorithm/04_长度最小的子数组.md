# 长度最小的子数组 — 学习笔记

- **日期：** 2026-07-14
- **题目：** [209. Minimum Size Subarray Sum](https://leetcode.cn/problems/minimum-size-subarray-sum/)
- **难度：** 中等
- **模式归类：** 滑动窗口
- **题解：** [B站视频](https://www.bilibili.com/video/BV1tZ4y1q7XE/)

---

## 核心思想

用一个可伸缩的窗口在数组上滑动。右指针负责扩展窗口直到和 ≥ target，左指针负责收缩窗口找到最短长度。

> 类比：借了一笔钱（target），每天赚一点钱逐天累加。一旦攒够了，就从最早赚的那天开始逐天去掉，看去掉后还够不够。记录"攒够钱的最少天数"。

---

## 关键步骤

1. `left = 0`, `sum = 0`, `minLen = Integer.MAX_VALUE`
2. `right` 从 0 遍历到末尾：
   - `sum += nums[right]`（右指针扩展窗口）
   - 当 `sum >= target` 时，进入收缩阶段：
     - 更新 `minLen = min(minLen, right - left + 1)`
     - `sum -= nums[left]`（左指针收缩窗口）
     - `left++`
     - 重复以上直到 `sum < target`
3. 返回 `minLen`（如果从未被更新过，返回 0）

---

## 时空复杂度

| 复杂度 | 值 | 推导 |
|--------|-----|------|
| 时间 | O(n) | left 和 right 各遍历数组一遍，不会回退 |
| 空间 | O(1) | 只用了 left, right, sum, minLen 四个变量 |

**关键：** 虽然看起来有嵌套 while，但 left 总共只会移动 n 次，所以整体是 O(n)。

---

## 易错点

1. **收缩是 while 不是 if** — 因为去掉一个元素后 sum 可能仍然 ≥ target，要继续收缩
2. **minLen 初始值要够大** — 用 `Integer.MAX_VALUE`，最后判断是否被更新过
3. **返回 0 的情况** — 所有元素加起来都 < target，minLen 从未更新
4. **数组元素全是正整数** — 这是滑动窗口能用的前提（负数的话窗口内和可能越加越小）

---

## Java 代码

```java
class Solution {
    public int minSubArrayLen(int target, int[] nums) {
        int left = 0, sum = 0;
        int minLen = Integer.MAX_VALUE;
        
        for (int right = 0; right < nums.length; right++) {
            sum += nums[right];                     // 扩展窗口
            
            while (sum >= target) {                 // 收缩窗口
                minLen = Math.min(minLen, right - left + 1);
                sum -= nums[left];
                left++;
            }
        }
        
        return minLen == Integer.MAX_VALUE ? 0 : minLen;
    }
}
```

## 滑动窗口模板（通用）

```java
int left = 0;
for (int right = 0; right < nums.length; right++) {
    加入窗口(nums[right]);            // 右指针扩展
    while (窗口需要收缩的条件) {
        更新结果();                     // 记录窗口长度
        移出窗口(nums[left]);          // 左指针收缩
        left++;
    }
}
```
