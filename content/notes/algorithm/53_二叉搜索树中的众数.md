# 53. 二叉搜索树中的众数

> 模式归类：BST 中序遍历（升序连续统计）

## 题目
给一棵 BST，返回其中**所有**出现次数最多的值（众数可能有多个）。

进阶要求：除递归隐式栈外，额外空间 O(1)。

## 核心思想
BST 中序遍历 = **升序序列**，相等的值必然**相邻连续**出现。
所以不用 HashMap 统计，只需要在遍历时**相邻比较**，动态更新最大次数。

## 示例树
```
       5
      / \
     3   8
    / \  / \
   2  3 7   9
  /     \
 1       8
```
中序遍历：1, 2, 3, 3, 5, 7, 8, 8, 9
- 3 出现 2 次、8 出现 2 次 → 众数 = **[3, 8]**（两个都返回）
- 相等值（3、3 和 8、8）在中序里紧挨着 → 相邻比较即可统计

## 关键步骤
1. 中序遍历（左→根→右），得到升序序列
2. 维护 4 个变量：
   - `prev`：上一个访问的节点（判断是否换值）
   - `curCount`：当前值出现次数
   - `maxCount`：历史最大次数
   - `result`：结果列表（可能多个众数）
3. 访问每个节点时：
   - 与 prev 相等 → `curCount++`（连续）
   - 与 prev 不等 → `prev = node; curCount = 1`（换新值，重新数）
4. 更新规则：
   - `curCount > maxCount` → 更新 maxCount，**清空**列表，加入自己
   - `curCount == maxCount` → 直接加入列表（又一个众数）
   - `curCount < maxCount` → 什么都不做（不够格）

## 为什么不能省略 prev 判空
第一个节点访问时 `prev == null`，直接 `prev.val` 会空指针。
用 `prev != null && node.val == prev.val`，短路求值保证不会崩，
且 prev 为 null 时自然走 else 分支（第一个节点计数 = 1）。

## 复杂度
- 时间 O(n)：每个节点访问一次
- 空间 O(1)（除递归栈 O(h)）：只用了 4 个变量，满足进阶要求

## Java 代码
```java
class Solution {
    TreeNode prev = null;        // 上一个访问的节点
    int curCount = 0;            // 当前值出现次数
    int maxCount = 0;            // 历史最大次数
    List<Integer> result = new ArrayList<>();

    public int[] findMode(TreeNode root) {
        inorder(root);
        int[] ans = new int[result.size()];
        for (int i = 0; i < result.size(); i++) {
            ans[i] = result.get(i);
        }
        return ans;
    }

    void inorder(TreeNode node) {
        if (node == null) return;
        inorder(node.left);

        if (prev != null && node.val == prev.val) {
            curCount++;                  // 同一个值，继续数
        } else {
            prev = node;                 // 换新值，重新数
            curCount = 1;
        }

        if (curCount > maxCount) {
            maxCount = curCount;
            result.clear();              // 旧众数全部作废
            result.add(node.val);
        } else if (curCount == maxCount) {
            result.add(node.val);        // 并列众数
        }

        inorder(node.right);
    }
}
```

## 易错点
1. `node.val =` vs `node.val ==` —— 赋值 vs 相等判断
2. `curCount = maxCount` vs `curCount == maxCount` —— 同上
3. prev 判空 —— 第一个节点 prev 是 null
4. result.clear() —— 出现更大次数时旧结果必须清空，否则残留
