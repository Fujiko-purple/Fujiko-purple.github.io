# 区间和 — 学习笔记

- **日期：** 2026-07-15
- **题目：** [卡码网 1070 区间和](https://kamacoder.com/problempage.php?pid=1070)
- **难度：** 简单
- **模式归类：** 前缀和

---

## 核心思想

先构建前缀和数组，再用 O(1) 时间回答任意区间和的查询。

> 类比：想算第 3 天到第 10 天的总花销 → 用"到第 10 天的累计"减去"到第 2 天的累计"。

---

## 关键步骤

1. 遍历原数组，计算前缀和 `p[i] = p[i-1] + nums[i]`
2. 每次查询区间 `[a, b]`：
   - `a == 0` → 结果 = `p[b]`
   - `a > 0` → 结果 = `p[b] - p[a-1]`

---

## 时空复杂度

| 阶段 | 时间 | 空间 |
|------|------|------|
| 构建前缀和 | O(n) | O(n) |
| 每次查询 | O(1) | — |

---

## 与暴力循环的对比

```
暴力：每次查询遍历 a~b 累计  → O(n) 每次，m 次查询 O(n×m)
前缀和：p[b] - p[a-1]        → O(1) 每次，m 次查询 O(n+m)
```

---

## 易错点

1. **a=0 时不能减 p[-1]** — 此时结果直接等于 p[b]
2. **前缀和长度跟原数组一样** — p[i] 是 0~i 的和
3. **输入处理（卡码网格式）** — 先读 n，再读 n 个数字，最后循环读查询对直到 EOF

---

## Java 代码（包含输入处理）

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int[] nums = new int[n];
        int[] prefix = new int[n];
        
        int sum = 0;
        for (int i = 0; i < n; i++) {
            nums[i] = sc.nextInt();
            sum += nums[i];
            prefix[i] = sum;
        }
        
        while (sc.hasNextInt()) {
            int a = sc.nextInt();
            int b = sc.nextInt();
            int result;
            if (a == 0) {
                result = prefix[b];
            } else {
                result = prefix[b] - prefix[a - 1];
            }
            System.out.println(result);
        }
        sc.close();
    }
}
```
