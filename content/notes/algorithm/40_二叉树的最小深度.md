## 题目
给定一个二叉树，找出其最小深度。最小深度是从根节点到最近叶子节点的最短路径上的节点数。

```
    3
   / \
  9  20
    /  \
   15   7

最小深度 = 2（路径 3→9）
```

```
    1
     \
      2
       \
        3

最小深度 = 3（只有一条路 1→2→3）
```

## 核心思想
和最大深度不同——**不能直接 `return min(左, 右) + 1`**。空子树深度为 0，但它不算叶子，会错误地"截断"路径。需要分情况处理。

## 关键步骤
1. 空节点返回 0
2. 递归求左右子树深度
3. 三种情况：
   - 左为空 → `right + 1`（只能走右边）
   - 右为空 → `left + 1`（只能走左边）
   - 都不为空 → `min(left, right) + 1`

## 时空复杂度

| 项目 | 复杂度 | 推导 |
|------|--------|------|
| 时间 | O(n) | 每个节点访问一次 |
| 空间 | O(h) | 递归栈深度 = 树高 |

## 模式归类：二叉树-深度递归（自底向上）

## ⚠️ 核心陷阱：为什么不能直接 `Math.min(left, right) + 1`？

```
    1         空子树深度=0，min(0, 3)=0
     \        直接 min+1 返回 1 → 错了！
      2       正确答案是 3（只有 1→2→3 这条路）
       \
        3
```

**叶子定义**：左右孩子都为 null 的节点。空子树不算叶子。

## Java 代码

### 递归
```java
public int minDepth(TreeNode root) {
    if (root == null) return 0;
    int left = minDepth(root.left);
    int right = minDepth(root.right);
    // 左子树为空 → 必须走右边
    if (root.left == null)  return right + 1;
    // 右子树为空 → 必须走左边
    if (root.right == null) return left + 1;
    // 两边都有 → 取小的
    return Math.min(left, right) + 1;
}
```

### BFS（层序，找到第一个叶子就返回，最优解）
```java
public int minDepth(TreeNode root) {
    if (root == null) return 0;
    Queue<TreeNode> queue = new LinkedList<>();
    queue.offer(root);
    int depth = 0;
    while (!queue.isEmpty()) {
        depth++;
        int size = queue.size();
        for (int i = 0; i < size; i++) {
            TreeNode node = queue.poll();
            if (node.left == null && node.right == null) {
                return depth;  // 第一个叶子，直接返回
            }
            if (node.left != null)  queue.offer(node.left);
            if (node.right != null) queue.offer(node.right);
        }
    }
    return depth;
}
```

### 和最大深度的对比

| | 最大深度 | 最小深度 |
|------|------|------|
| 核心公式 | `max(左, 右) + 1` | 分三种情况 |
| null 子树处理 | 不影响（max 自然忽略 0） | **必须跳过**，否则被 0 截断 |
| 最优 BFS | DFS=BFS 都要全遍历 | BFS 更好（找到叶子就停） |

## 易错点
1. 直接 `Math.min(left, right) + 1` 是经典错误写法
2. 注意分支顺序：先判空子树，再取 min
