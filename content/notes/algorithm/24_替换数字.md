# 替换数字 — 学习笔记

- **日期：** 2026-07-18
- **题目：** 卡码网 54. 替换数字
- **难度：** 简单
- **模式归类：** 双指针-从后往前填充
- **题解：** [B站视频](https://www.bilibili.com/video/BV1M94y1f7XP/)

---

## 核心思想

把每个数字字符替换成 "number"。**从后往前双指针填充**，避免覆盖未处理的字符。

---

## 为什么从后往前？

```
原始: a 1 b
从前往后：写完 "number" 后，'b' 被覆盖 → ❌
从后往前：old 和 new 各走各的，互不干扰 → ✅
```

---

## 代码（双指针版）

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        String s = sc.next();

        // 1. 统计数字个数
        int count = 0;
        for (int i = 0; i < s.length(); i++) {
            if (s.charAt(i) >= '0' && s.charAt(i) <= '9') {
                count++;
            }
        }

        // 2. 扩容（每个数字多占5位，因为 "number" 比一个数字长5）
        char[] arr = new char[s.length() + count * 5];
        for (int i = 0; i < s.length(); i++) {
            arr[i] = s.charAt(i);
        }

        // 3. 从后往前双指针填充
        int old = s.length() - 1;
        int newIdx = arr.length - 1;

        while (old >= 0) {
            if (arr[old] >= '0' && arr[old] <= '9') {
                // 倒着写 "number"
                arr[newIdx--] = 'r';
                arr[newIdx--] = 'e';
                arr[newIdx--] = 'b';
                arr[newIdx--] = 'm';
                arr[newIdx--] = 'u';
                arr[newIdx--] = 'n';
            } else {
                arr[newIdx--] = arr[old];
            }
            old--;
        }

        System.out.println(new String(arr));
    }
}
```

---

## 关键点

1. **先算后扩** — 统计数字个数，再算新数组长度 = 原长 + 数字数 × 5
2. **从后往前** — old 从原末尾往前扫，newIdx 从新末尾往前填
3. **写 "number" 是倒序** — 因为 new 也在从右往左移动，先写 r 再写 e...最终读出来是正序
4. **old 不会覆盖** — old 永远在 new 的左边，两个指针各走各的

---

## 新语法

| 语法 | 说明 |
|------|------|
| `c >= '0' && c <= '9'` | 判断字符是否是数字（不是 `isDigit`） |
| `sc.next()` | 从输入读一个字符串（`sc.nextInt()` 你已会） |
| `new String(arr)` | 字符数组 → 字符串 |
