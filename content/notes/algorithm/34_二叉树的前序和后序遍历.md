## 核心思想

```
前序（根左右）：根 → 左子树 → 右子树
后序（左右根）：左子树 → 右子树 → 根

递归函数里三行代码换位置 = 不同遍历
```

## 三种遍历对比

```
       1
      / \
     2   3
    / \
   4   5

前序：1→2→4→5→3    （根在最前）
中序：4→2→5→1→3    （根在中间）
后序：4→5→2→3→1    （根在最后）
```

---

## 代码

```java
// 前序：根左右
class Solution {
    List<Integer> res = new ArrayList<>();
    public List<Integer> preorderTraversal(TreeNode root) {
        if (root == null) return res;
        res.add(root.val);               // ① 根
        preorderTraversal(root.left);    // ② 左
        preorderTraversal(root.right);   // ③ 右
        return res;
    }
}

// 后序：左右根
class Solution {
    List<Integer> res = new ArrayList<>();
    public List<Integer> postorderTraversal(TreeNode root) {
        if (root == null) return res;
        postorderTraversal(root.left);   // ① 左
        postorderTraversal(root.right);  // ② 右
        res.add(root.val);               // ③ 根
        return res;
    }
}
```

## 关键点

1. 三行代码顺序一换 = 不同遍历，结构完全一样
2. `if (root == null) return res` — 递归终止条件
3. `res` 作为类成员变量，递归中共享同一个列表
4. 时间复杂度 O(n)，每个节点走一次
