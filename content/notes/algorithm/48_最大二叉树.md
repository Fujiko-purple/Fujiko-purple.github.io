## 题目
给定一个不含重复元素的整数数组 nums，用该数组构建一棵最大二叉树：

1. 最大值 = 根节点
2. 最大值左边的子数组 = 左子树（递归构建）
3. 最大值右边的子数组 = 右子树（递归构建）

```
输入：nums = [3, 2, 1, 6, 0, 5]

输出：
        6
      /   \
     3     5
      \   /
       2 0
        \
         1
```

## 核心思想
**数组分治构造树**。与"从中序+后序构造二叉树"是同类题——在一个范围内找到根（这里是最大值），然后左右分割递归。

## 关键步骤
1. 在数组区间 [left, right] 中找到最大值下标 maxIdx
2. 以 nums[maxIdx] 为根
3. 左子树 = 递归构造 [left, maxIdx - 1]
4. 右子树 = 递归构造 [maxIdx + 1, right]

## 时空复杂度

| 项目 | 复杂度 | 推导 |
|------|--------|------|
| 时间 | O(n²) 最坏 | 有序数组退化为单链表，每轮扫描 O(n) |
| 空间 | O(h) | 递归栈深度 |

## 模式归类：二叉树-数组分治构造（最大值定根 + 递归分割）

## Java 代码

```java
public TreeNode constructMaximumBinaryTree(int[] nums) {
    return build(nums, 0, nums.length - 1);
}

TreeNode build(int[] nums, int left, int right) {
    if (left > right) return null;

    // 在当前区间找到最大值下标
    int maxIdx = left;
    for (int i = left; i <= right; i++) {
        if (nums[i] > nums[maxIdx]) {
            maxIdx = i;
        }
    }

    TreeNode root = new TreeNode(nums[maxIdx]);

    root.left = build(nums, left, maxIdx - 1);
    root.right = build(nums, maxIdx + 1, right);

    return root;
}
```

## 易错点
1. ⚠️ `maxIdx` 初始化为 `left`，不是 0——递归到子区间时不能从数组开头找
2. 空区间（`left > right`）返回 null
3. 数组元素不重复，简化了最大值查找

## 与"中序+后序构造"类比

| | 中序+后序构造 | 最大二叉树 |
|--|------------|----------|
| 输入 | 两个数组 in + post | 一个数组 nums |
| 根怎么确定 | post 最后一个 | 区间内最大值 |
| 分割依据 | 根在中序中的位置 | 最大值下标 |
| 递归参数 | 6 个 | 3 个（含数组本身） |
| 核心操作 | HashMap 查下标 | 线性扫描找最大值 |
