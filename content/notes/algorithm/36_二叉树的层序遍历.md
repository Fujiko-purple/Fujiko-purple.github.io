# 二叉树的层序遍历 — 学习笔记

- **日期：** 2026-07-24
- **题目：** [102. Binary Tree Level Order Traversal](https://leetcode.cn/problems/binary-tree-level-order-traversal/description/)
- **难度：** 中等
- **模式归类：** 二叉树 / BFS / 队列
- **题解：** [B站视频](https://www.bilibili.com/video/BV1GY4y1u7b2/)

---

## 核心思想

```
用队列 BFS，一层一层扫
队列 size = 当前这层有几个节点
每轮处理一层 → 把它们的值塞篮子 → 顺便把孩子入队
```

## 图解

```
       1
      / \
     2   3
    / \   \
   4   5   6

初始: queue = [1]

① size=1, poll 1 → 孩子2,3入队
   level=[1]  queue=[2,3]

② size=2, poll 2 → 孩子4,5入队
          poll 3 → 孩子6入队
   level=[2,3]  queue=[4,5,6]

③ size=3, poll 4,5,6 → 都没孩子
   level=[4,5,6]  queue=[]

结果: [[1], [2,3], [4,5,6]]
```

---

## 代码

```java
class Solution {
    public List<List<Integer>> levelOrder(TreeNode root) {
        List<List<Integer>> res = new ArrayList<>();
        if (root == null) return res;

        Queue<TreeNode> queue = new LinkedList<>();
        queue.offer(root);

        while (!queue.isEmpty()) {
            int size = queue.size();           // 这层有几个人
            List<Integer> level = new ArrayList<>();

            for (int i = 0; i < size; i++) {
                TreeNode node = queue.poll();   // 队头出列
                level.add(node.val);
                if (node.left  != null) queue.offer(node.left);
                if (node.right != null) queue.offer(node.right);
            }
            res.add(level);
        }
        return res;
    }
}
```

## 关键点

1. `queue.size()` = 当前层节点数，必须提前记（for 循环里会变）
2. `poll` 出队 → 值放进 level → 孩子 `offer` 入队
3. `Queue<TreeNode>` 用 `LinkedList` 实现（§23）
4. `List<List<Integer>>` 嵌套泛型（§16），外层每层一个 List
5. 时间复杂度 O(n)
