## 题目
给定二叉树根节点 root 和一个整数 targetSum，判断是否存在**根到叶子**的路径，路径上所有节点值之和等于 targetSum。

```
        5
       / \
      4   8
     /   / \
    11  13  4
   /  \      \
  7    2      1

targetSum = 22
路径：5 → 4 → 11 → 2 = 22 → true
```

## 核心思想
DFS 遍历，沿途累加节点值。到叶子节点时判断累加和是否等于 targetSum。与"二叉树的所有路径"是同一框架——把"拼接字符串"换成"累加和"。

## 关键步骤
1. 空节点 → 返回 false
2. 累加当前节点值到 sum
3. 叶子节点 → 判断 sum == targetSum，是则返回 true
4. 非叶子 → 递归左右子树，用 `||` 合并结果（两边有一个找到即可）

## 时空复杂度

| 项目 | 复杂度 | 推导 |
|------|--------|------|
| 时间 | O(n) | 每个节点访问一次 |
| 空间 | O(h) | 递归栈深度 |

## 模式归类：二叉树-路径和判定（DFS + 累加 + 逻辑合并）

## Java 代码

```java
public boolean hasPathSum(TreeNode root, int targetSum) {
    return dfs(root, 0, targetSum);
}

boolean dfs(TreeNode node, int sum, int targetSum) {
    if (node == null) return false;

    sum = sum + node.val;

    // 叶子节点：判断和是否等于 target
    if (node.left == null && node.right == null) {
        return sum == targetSum;   // 等价于 if(sum==targetSum) true; else false;
    }

    // 非叶子：左或右有一条路径满足即可
    boolean leftResult = dfs(node.left, sum, targetSum);
    boolean rightResult = dfs(node.right, sum, targetSum);
    return leftResult || rightResult;
}
```

## 易错点
1. ⚠️ 空树（root == null）直接返回 false，不可能是 true
2. `sum + node.val` 不回溯——Java 基础类型传值拷贝，递归返回时 sum 自动恢复，不用手动恢复
3. 必须到**叶子**才判断，不是到任意节点
4. `||` 合并：左找到了就直接返回 true，不会再去右子树（短路求值）

## 与原题"二叉树的所有路径"对照

| | 路径之和 | 所有路径 |
|--|---------|---------|
| 传参 | int sum（累加和） | String path（拼接字符串） |
| 叶子处理 | 判断 sum == target | 保存 path 到结果列表 |
| 返回 | boolean（是否存在） | void（结果写进列表） |
