# 移除元素 — 学习笔记

- **日期：** 2026-07-14
- **题目：** [27. Remove Element](https://leetcode.cn/problems/remove-element/)
- **难度：** 简单
- **模式归类：** 双指针-快慢指针
- **题解：** [B站视频](https://www.bilibili.com/video/BV12A4y1Z7LP/)

---

## 核心思想

数组不能真的删除元素。**"原地移除" = 把要保留的元素全部搬到数组前面，返回好元素的个数。**

> 类比：整理书架——好书放左边第一个空位，坏书跳过不处理。最后左边全是好书，slow 的位置就是好书数量。

---

## 关键步骤

1. `slow = 0`（下一个好元素放的位置）
2. `fast` 从 0 到末尾遍历：
   - `nums[fast] == val` → 跳过，slow 不动
   - `nums[fast] != val` → `nums[slow] = nums[fast]`，slow 右移 1
3. 返回 `slow`（好元素个数）

---

## 时空复杂度

| 复杂度 | 值 | 推导 |
|--------|-----|------|
| 时间 | O(n) | fast 扫描一遍 |
| 空间 | O(1) | 原地操作，无额外数组 |

---

## 易错点

1. **不要用 `nums[fast] == -1` 标记删除** — Java 数组没有"删除"，标记没用
2. **slow 是返回值，不是坏元素个数** — slow = 好元素数量
3. **fast 和 slow 的关系**：fast 永远 >= slow，fast 跑在前面找好元素，slow 在后面记录位置

---

## Java 代码

```java
class Solution {
    public int removeElement(int[] nums, int val) {
        int slow = 0;
        for (int fast = 0; fast < nums.length; fast++) {
            if (nums[fast] != val) {
                nums[slow] = nums[fast];
                slow++;
            }
        }
        return slow;
    }
}
```
