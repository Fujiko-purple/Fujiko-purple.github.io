# 右旋字符串 — 学习笔记

- **日期：** 2026-07-20
- **题目：** 卡码网 55. 右旋字符串
- **难度：** 中等
- **模式归类：** 双指针-两端指针（三步反转法）
- **题解：** 无（自己推导）

---

## 核心思想

**三步反转法**——和第 25 题完全一样的底层思路：整体反转 + 局部反转。

```
输入: "abcdefg", k=2
目标: "fgabcde"（右边 k 个字符移到左边）

① 整个反转     → "gfedcba"
② 反转前 k 个   → "fgedcba"
③ 反转后面全部   → "fgabcde"
```

---

## 代码

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int k = sc.nextInt();
        String s = sc.next();

        char[] arr = s.toCharArray();

        reverse(arr, 0, arr.length - 1);        // ① 整体反转
        reverse(arr, 0, k - 1);                 // ② 前 k 个反转回来
        reverse(arr, k, arr.length - 1);        // ③ 后面反转回来

        System.out.println(new String(arr));
    }

    private static void reverse(char[] arr, int left, int right) {
        while (left < right) {
            char temp = arr[left];
            arr[left] = arr[right];
            arr[right] = temp;
            left++; right--;
        }
    }
}
```

---

## 关键点

1. **三步反转法** — 整体 + 两段分别反转，跟第 25 题同源
2. 这里的三步比第 25 题更简洁——不需要去空格、不需要识别单词
3. 直接调用同一个 `reverse` 方法三次
