## 核心思想

两个一组，改三根绳子完成交换。每组交换完后，prev 跳到这一组的第二个节点（即原来的 n1），继续处理下一组。

---

## 口诀：prev 指 n2 → n1 抓后面 → n2 指 n1

```
原状态:     prev → n1 → n2 → next

① prev.next = n2       // prev 跳过 n1，直连 n2
② n1.next = n2.next    // n1 抓住 n2 后面的节点（防止丢失）
③ n2.next = n1         // n2 反向指向 n1（交换完成）

新状态:     prev → n2 → n1 → next
```

---

## 为什么这个顺序

- ②必须在③之前：n2.next 一旦被改，n1 就找不到后面的节点了
- ①可以在任意时候做（因为 n1 已被变量保存）

---

## 时空复杂度

| 复杂度 | 值 |
|--------|----|
| 时间 | O(n) |
| 空间 | O(1) |

## Java 代码

```java
class Solution {
    public ListNode swapPairs(ListNode head) {
        ListNode dummy = new ListNode(0, head);
        ListNode prev = dummy;
        
        while (prev.next != null && prev.next.next != null) {
            ListNode n1 = prev.next;
            ListNode n2 = n1.next;
            
            prev.next = n2;          // ①
            n1.next = n2.next;       // ②
            n2.next = n1;            // ③
            
            prev = n1;  // 跳到这一对的第二个节点
        }
        
        return dummy.next;
    }
}
```

---

## 循环条件解释

`prev.next != null && prev.next.next != null`：

- `prev.next == null` → 没有节点了，停止
- `prev.next.next == null` → 只剩一个节点，没法配对，停止
