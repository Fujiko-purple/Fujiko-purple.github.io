# 两数之和 — 学习笔记

- **日期：** 2026-07-18
- **题目：** [1. Two Sum](https://leetcode.cn/problems/two-sum/)
- **难度：** 简单
- **模式归类：** 哈希表-HashMap（值→下标映射）
- **题解：** [B站视频](https://www.bilibili.com/video/BV1aT41177mK/)

---

## 核心思想

遍历数组，对于每个数 `nums[i]`，去 HashMap 里找有没有 `target - nums[i]`。
有 → 返回两个下标；没有 → 把当前数存入 map，继续遍历。

**为什么 HashMap 而不是 HashSet？**
因为不仅要判断"有没有"，还要**返回下标**。HashMap 存的是 `值 → 下标`。

---

## 代码

```java
public int[] twoSum(int[] nums, int target) {
    HashMap<Integer, Integer> map = new HashMap<>();
    for (int i = 0; i < nums.length; i++) {
        int complement = target - nums[i];
        if (map.containsKey(complement)) {
            return new int[]{map.get(complement), i};
        }
        map.put(nums[i], i);
    }
    return new int[0];
}
```

---

## 关键点

1. `new int[]{a, b}` 用大括号，不是小括号
2. HashMap<key类型, value类型>，这里 key=数组值，value=下标
3. 先查后放，避免同一个元素用两次
4. 时间复杂度 O(n)，空间 O(n)

---

## 易错点

```java
// ❌ 错误：用小括号
return new int(map.get(complement), i);

// ❌ 错误：给返回值命名
return new int[] num = {a, b};

// ✅ 正确
return new int[]{map.get(complement), i};
```
