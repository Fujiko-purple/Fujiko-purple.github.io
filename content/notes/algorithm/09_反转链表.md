## 核心思想

遍历链表，逐一把每个节点的 `next` 绳子调转方向。

---

## 口诀（记这一句就够了）

> **记后路 → 断绳子 → prev走 → curr走**

```
① next = curr.next    // 记后路：先抓住后面的节点
② curr.next = prev    // 断绳子：把当前节点指向前一个
③ prev = curr         // prev 走：prev 前进到当前节点
   curr = next         // curr 走：curr 前进到下一个节点
```

---

## 为什么顺序不能乱

②必须在①之后——绳子断了才找后路就找不到了。
③必须在②之后——先把 prev 移到当前位置，再移 curr。

---

## 时空复杂度

| 复杂度 | 值 |
|--------|----|
| 时间 | O(n) — 遍历一遍 |
| 空间 | O(1) — 只用了三个指针 |

---

## Java 代码

```java
class Solution {
    public ListNode reverseList(ListNode head) {
        ListNode prev = null;
        ListNode curr = head;
        while (curr != null) {
            ListNode next = curr.next;   // ① 记后路
            curr.next = prev;            // ② 调转绳子
            prev = curr;                 // ③ prev 前移
            curr = next;                 // ③ curr 前移
        }
        return prev;  // prev 是新头，curr 已经是 null
    }
}
```

---

## 为什么返回 prev 而不是 curr

循环结束时 `curr == null`，`prev` 指向最后一个处理的节点（即原链表的尾节点，新链表的头节点）。
