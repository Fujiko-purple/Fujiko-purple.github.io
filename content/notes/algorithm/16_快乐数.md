# 快乐数 — 学习笔记

- **日期：** 2026-07-17
- **题目：** [202. Happy Number](https://leetcode.cn/problems/happy-number/)
- **难度：** 简单
- **模式归类：** 哈希表-HashSet（循环检测）
- **题解：** 无

---

## 核心思想

用 HashSet 记录每一步出现的数。数字重复出现 = 进入死循环 = 不是快乐数。

> 类比：在操场跑步，如果你经过了同一个地点两次，说明你在绕圈——永远到不了终点。

---

## 关键步骤

1. `while (n != 1)` 循环
2. 计算 `n` 的各位平方和 → 新 `n`
3. 如果 `set.contains(n)` → 循环了，return false
4. 否则 `set.add(n)`，继续
5. n == 1 时 return true

---

## 为什么不会无限增大

- 999 → 243，9999 → 324
- 位数越多，平方和反而相对越小
- 所有数最终落入 [1, 243] 范围内 → 要么到 1，要么循环

---

## Java 代码

```java
import java.util.*;

class Solution {
    public boolean isHappy(int n) {
        HashSet<Integer> set = new HashSet<>();
        while (n != 1) {
            n = getNext(n);
            if (set.contains(n)) return false;
            set.add(n);
        }
        return true;
    }
    
    // 计算各位平方和
    private int getNext(int n) {
        int sum = 0;
        while (n > 0) {
            int d = n % 10;      // 取最后一位
            sum += d * d;        // 平方后累加
            n = n / 10;          // 去掉最后一位
        }
        return sum;
    }
}
```

---

## `getNext` 的拆解

```
n = 19:
  19 % 10 = 9 → sum += 81, n = 19 / 10 = 1
  1 % 10 = 1  → sum += 1,  n = 1 / 10 = 0
  退出循环，返回 sum = 82
```

---

## 模式：HashSet 做"循环检测"

任何"判断会不会重复"的问题，都可以用 HashSet 记录已经见过的值。
