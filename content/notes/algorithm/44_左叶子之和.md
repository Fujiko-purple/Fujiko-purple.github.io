## 题目
给定二叉树的根节点 root，返回所有左叶子之和。

```
    3
   / \
  9  20
    /  \
   15   7

左叶子：9、15 → 和 = 24
```

## 核心思想
左叶子需要在**父节点**判断。条件：`root.left != null && root.left 是叶子（左右都 null）`。

## 关键步骤
1. 空节点返回 0
2. 判断当前节点的左孩子是否为左叶子（非空且左右都为空）→ 加上左叶子的值
3. 递归累加左右子树的左叶子之和

## 时空复杂度

| 项目 | 复杂度 | 推导 |
|------|--------|------|
| 时间 | O(n) | 每个节点访问一次 |
| 空间 | O(h) | 递归栈深度 |

## 模式归类：二叉树-节点判断（左叶子）

## Java 代码

```java
public int sumOfLeftLeaves(TreeNode root) {
    if (root == null) return 0;

    int sum = 0;

    // 在父节点判断左叶子
    if (root.left != null && root.left.left == null && root.left.right == null) {
        sum += root.left.val;  // 注意：加的是左叶子的值，不是当前节点
    }

    sum += sumOfLeftLeaves(root.left);
    sum += sumOfLeftLeaves(root.right);

    return sum;
}
```

## 易错点
1. ⚠️ `sum += root.left.val` 不是 `sum += root.val`，加的是左叶子自身
2. 左叶子 = 左孩子 + 叶子，两条缺一不可
3. 判断只能放在父节点做，走到左孩子本身已经无法区分它是父节点的左还是右
