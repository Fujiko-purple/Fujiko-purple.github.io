# 前 K 个高频元素 — 学习笔记

- **日期：** 2026-07-24
- **题目：** [347. Top K Frequent Elements](https://leetcode.cn/problems/top-k-frequent-elements/description/)
- **难度：** 中等
- **模式归类：** 堆（优先队列 PriorityQueue）
- **题解：** [B站视频](https://www.bilibili.com/video/BV1Xg41167Lz/)

---

## 核心思想

```
① HashMap 统计每个数的频次
② 小顶堆（按频次排序），保持堆大小 = k
   新人进门 → 超员了就踢掉堆顶（频次最低的那个）
③ 堆里剩下的就是前 k 高
```

---

## 图解

```
nums = [1, 1, 1, 2, 2, 3],  k = 2

① 统计: {1:3, 2:2, 3:1}

② 遍历去重后的 {1, 2, 3}，按频次入堆：

1(3次) → 堆空，进      堆: [1]           size=1 < k
2(2次) → 堆未满，进     堆: [1, 2]        size=2 = k  堆顶=2(频次最低)
3(1次) → 进堆          堆: [2, 1, 3]     size=3 > k!
       → 踢堆顶(3)      堆: [1, 2]        size=2 = k

③ 堆里: [1, 2] ← 答案
```

---

## 代码

```java
class Solution {
    public int[] topKFrequent(int[] nums, int k) {
        // ① 统计频次
        HashMap<Integer, Integer> map = new HashMap<>();
        for (int n : nums) {
            map.put(n, map.getOrDefault(n, 0) + 1);
        }

        // ② 小顶堆：按频次排序
        PriorityQueue<Integer> pq = new PriorityQueue<>(
            (a, b) -> map.get(a) - map.get(b)
        );

        for (int n : map.keySet()) {
            pq.offer(n);
            if (pq.size() > k) {
                pq.poll();  // 踢掉频次最低的
            }
        }

        // ③ 取出答案
        int[] res = new int[k];
        for (int i = 0; i < k; i++) {
            res[i] = pq.poll();
        }
        return res;
    }
}
```

---

## 关键点

1. 小顶堆堆顶 = 当前堆里频次**最低**的
2. `(a, b) -> map.get(a) - map.get(b)` — Lambda 告诉堆按频次比大小
3. 堆满了踢掉堆顶 — 堆里永远只保留"前 k 名"
4. 时间复杂度 O(n log k)，空间 O(n)
5. 别用大顶堆（全入再取 k 个）— 比小顶堆慢
