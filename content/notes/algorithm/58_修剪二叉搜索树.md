# 58 · 修剪二叉搜索树

> LeetCode 669 | 中等 | 标签：深度优先搜索 二叉树

## 核心思想（一句话）

**范围外节点必有一侧整棵子树非法**（BST 性质推论）——扔自己 + 扔非法侧，另一侧修剪完顶上；范围内节点保留，两边递归修剪。

## 为什么不需要 57 的"接班人"逻辑

| | 57 删除 | 58 修剪 |
|--|------|------|
| 删谁 | 指定的 key，**可能恰好两子齐全** | 范围外节点，**至少一侧子树全非法** |
| 两子怎么处理 | 找接班人值顶替 | **不会发生**：值 < low 的左子树全 < low；值 > high 的右子树全 > high |
| 删除方式 | 值顶替 + 递归删原接班人 | 整棵子树丢弃，另一侧顶上 |

## 三种走向

| 条件 | 动作 |
|------|------|
| `root.val > high` | 扔自己 + 扔右子树（右子树全 > root > high），左子树修剪后顶上 |
| `root.val < low` | 扔自己 + 扔左子树（左子树全 < root < low），右子树修剪后顶上 |
| `low <= root.val <= high` | 保留，`root.left` / `root.right` 递归修剪并挂回 |

## 树图示例

### 删前（low=1, high=3）

```
        3
       / \
      0   4        ← 0 < 1 非法（左子树空，无连坐）
       \             ← 4 > 3 非法（右子树空）
        2
       /
      1            ← 1、2 合法（1 >= low）
```

### 递归过程

```
        3   → 在 [1,3] 内，保留；递归修剪左右
       / \
      0   4   → 0 < 1：return trimBST(0.right) = 2 顶上来
       \        → 4 > 3：return trimBST(4.left) = null
        2   → 在 [1,3] 内，保留；修剪左右（1 保留，右空）
       /
      1
```

### 删后

```
        3
       /
      2
     /
    1
```

中序遍历 1,2,3 升序 ✓，BST 性质保持。

## 关键步骤

1. 递归遍历每个节点，判断是否在 [low, high] **闭区间**内（端点也要保留！）
2. 范围外：返回值 = 另一侧子树修剪后的结果（**必须递归修剪**，那侧内部可能有漏网的非法节点）
3. 范围内：保留自身，左右子树递归修剪后挂回

## 易错点

- `return root.left` 是错的——直接返回未修剪的子树会带回非法节点，必须 `return trimBST(root.left, low, high)`
- 边界是 `<= >=`：`val == low` 或 `val == high` 的节点必须保留（写 `> high` / `< low` 判断扔，else 全保留）
- 扔自己时**不需要挂回**（整棵子树顶替父节点位置），范围内才需要挂回

## 复杂度

- 时间：O(n)（每个节点最多访问一次）
- 空间：O(h)（递归栈）

## 最终代码

```java
class Solution {
    public TreeNode trimBST(TreeNode root, int low, int high) {
        if (root == null) return null;

        if (root.val > high) {
            return trimBST(root.left, low, high);    // 扔自己+右子树，左子树修剪后顶上
        } else if (root.val < low) {
            return trimBST(root.right, low, high);   // 扔自己+左子树，右子树修剪后顶上
        } else {
            root.left = trimBST(root.left, low, high);   // 自己在范围内：局部修剪，挂回
            root.right = trimBST(root.right, low, high);
            return root;
        }
    }
}
```

## 一句话应用场景

数据库按时间区间查询历史记录、统计报表按数值范围过滤——"区间之外整体丢弃，区间之内逐点检查"。
