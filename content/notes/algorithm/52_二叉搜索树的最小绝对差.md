## 题目
给定一棵二叉搜索树（BST），返回任意两不同节点值之间的最小差值（绝对值）。

```
        4
       / \
      2   6
     / \
    1   3

输出：1（相邻节点差，如 1 和 2，2 和 3，3 和 4）
```

## 核心思想
**BST 中序遍历 = 升序序列**。在升序序列中，最小差值一定出现在相邻元素之间。中序遍历时用 `prev` 记录前驱节点，每访问一个节点就计算与前任的差值，实时更新最小值。

## 关键步骤
1. 定义成员变量 `prev`（前驱节点）和 `minDiff`（最小差值）
2. 中序遍历：左 → 根 → 右
3. 每到达一个节点时，若 `prev != null`，计算 `node.val - prev.val`
4. 用 `Math.min` 更新最小差值
5. 更新 `prev = node`
6. 继续遍历右子树

## 时空复杂度

| 项目 | 复杂度 | 推导 |
|------|--------|------|
| 时间 | O(n) | 每个节点访问一次 |
| 空间 | O(h) | 递归栈深度 |

## 模式归类：BST-中序遍历相邻（prev 指针 + 实时最小值）

## Java 代码

```java
TreeNode prev = null;
int minDiff = Integer.MAX_VALUE;

public int getMinimumDifference(TreeNode root) {
    inorder(root);
    return minDiff;
}

void inorder(TreeNode node) {
    if (node == null) return;

    inorder(node.left);  // 左

    // 根：与前驱节点比较
    if (prev != null) {
        minDiff = Math.min(minDiff, node.val - prev.val);
    }
    prev = node;  // 更新前驱

    inorder(node.right);  // 右
}
```

## 易错点
1. ⚠️ 比较的是 `node.val - prev.val`（当前节点值 - 前驱节点值），不是 `node.val - node.left.val`——中序前驱不一定是左孩子
2. `prev` 必须是**成员变量**，不是局部变量——递归调用之间共享状态
3. 中序的 prev 更新时机：**处理完当前节点后**才更新，不是进入左子树之前
4. 差值一定为正（中序升序），不需要绝对值
