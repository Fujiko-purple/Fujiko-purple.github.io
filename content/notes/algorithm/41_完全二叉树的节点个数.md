# 完全二叉树的节点个数（LeetCode 222）

## 题目

给一棵完全二叉树，求节点总数。要求利用完全二叉树性质比 O(n) 更快。

## 核心思想

判断当前子树是不是**满二叉树**（左深 = 右深）。是 → 直接套公式 `2^h - 1`；不是 → 拆成左右子树递归算。

## 关键步骤

1. 空节点返回 0
2. 一路向左算高度 `leftH`，一路向右算高度 `rightH`
3. `leftH == rightH` → 满二叉树，返回 `(1 << leftH) - 1`
4. 不相等 → `countNodes(左) + countNodes(右) + 1`

## 时空复杂度

| 项目 | 复杂度    | 推导                                        |
| ---- | --------- | ------------------------------------------- |
| 时间 | O(log² n) | 每次递归 O(log n) 算高度，递归深度 O(log n) |
| 空间 | O(log n)  | 递归栈                                      |

## 模式归类：二叉树-完全二叉树性质

## 满二叉树节点数公式

- h 层满二叉树：节点数 = 2^h - 1
- `1 << h` = 2^h（位运算，左移 h 位）

## Java 代码

```java
public int countNodes(TreeNode root) {
    if (root == null) return 0;

    int leftH = 0, rightH = 0;
    TreeNode p = root, q = root;

    // 一路向左
    while (p != null) { leftH++; p = p.left; }
    // 一路向右
    while (q != null) { rightH++; q = q.right; }

    if (leftH == rightH) {
        return (1 << leftH) - 1;  // 2^h - 1
    }
    return countNodes(root.left) + countNodes(root.right) + 1;
}
```

### 暴力法（O(n)，不推荐但也要会）

```java
public int countNodes(TreeNode root) {
    if (root == null) return 0;
    return countNodes(root.left) + countNodes(root.right) + 1;
}
```

## 易错点

1. `1 << h` 不要写成 `1 << leftH - 1`，位运算优先级低于减号，必须加括号 `(1 << leftH) - 1`
2. 左右高度分别声明两个指针，不要用一个指针串行跑
