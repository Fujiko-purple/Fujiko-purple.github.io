# 59 · 将有序数组转化为二叉搜索树

> LeetCode 108 | 简单 | 标签：二叉树 分治

## 核心思想（一句话）

升序数组就是 BST 的**中序遍历序列**；要构造出**高度平衡**的树，每次取区间**中间值做根**，左右分治递归。

## 数组分治构造模式（与 48 题同款）

| | 48 最大二叉树 | 59 有序数组→BST |
|--|------|------|
| 选根方式 | 区间内**最大值**做根 | 区间**中间值**做根 |
| 为什么要这样选 | 题意要求 | 平衡要求（左右势力均衡） |
| 分治 | 左右两侧递归 | 左右两侧递归 |
| 终止 | 区间空 | 区间空（`left > right`） |

## 树图示例（[1,2,3,4,5]）

```
第一步 区间[0,4] mid=2 → 根 3
        3
       / \
 [0,1]     [3,4]

第二步 左区间[0,1] mid=0 → 1；右区间[3,4] mid=3 → 4
        3
       / \
      1   4
       \   \
       2   5      ← 第三步：1 的右区间[1,1] → 2；4 的右区间[4,4] → 5

最终（中序 1,2,3,4,5 ✓，各节点左右高度差 ≤ 1 ✓）：
        3
       / \
      1   4
       \   \
        2   5
```

偶数长度 [1,2]：`mid = 0 + (1-0)/2 = 0` → 根 1，右子树 2（**mid 向下取整**，偏左）

## 关键步骤（区间三件套）

1. **mid 取中**：`mid = left + (right - left) / 2`（防溢出写法）
2. **边界收窄**：左子树 `[left, mid-1]`，右子树 `[mid+1, right]`——**mid 自己做了根，不能传给子树**
3. **left > right 收工**：区间空 → return null

## 易错点

- 终止条件是 `left > right`（空区间），不是 `left == right`（还剩一个元素）
- 区间左边界不能写死 `0`、右边界不能写死 `nums.length-1`——递归下去必须跟着 `left/right` 变
- `new TreeNode(nums[mid])` 要传值
- 参数之间用逗号，不是分号（`int left, int right`）

## 复杂度

- 时间：O(n)（每个元素恰好创建一次）
- 空间：O(log n)（递归栈 = 平衡树高）

## 最终代码

```java
class Solution {
    public TreeNode sortedArrayToBST(int[] nums) {
        return build(nums, 0, nums.length - 1);
    }

    TreeNode build(int[] nums, int left, int right) {
        if (left > right) {              // 区间空：无元素可取
            return null;
        }
        int mid = left + (right - left) / 2;   // 取中间（防溢出）
        TreeNode root = new TreeNode(nums[mid]);
        root.left = build(nums, left, mid - 1);    // 左半数组 → 左子树
        root.right = build(nums, mid + 1, right);  // 右半数组 → 右子树
        return root;
    }
}
```

## 一句话应用场景

数据库把排序好的结果集建索引树、把中序遍历序列还原成平衡树——"有序数据均匀切分，层层分治"。
