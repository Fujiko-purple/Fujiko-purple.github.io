## 题目

给定两个整数 `n` 和 `k`，返回范围 `[1, n]` 中所有可能的 **k 个数的组合**。

**示例**：n=4, k=2 → `[[1,2],[1,3],[1,4],[2,3],[2,4],[3,4]]`

## 核心思想（一句话）

**回溯 = 树形枚举 + 走不通就回头**：把"选数"画成一棵树，从根往下每层选一个数，选满 k 个就收获，走到底/走不下去就**退回上一层换一条路**——这个"退回再换路"就是回溯。

## 你的手算就是回溯

手算顺序 `12 → 13 → 14 → 23 → 24 → 34`，画成树：

```
            start
         ┌───┼───┬───┐
         1   2   3   4
        ┌┼┐ ┌┼┐  │
        2 3 4 3 4 4
```

第一个数从 1 起，第二个数**永远选比它大的**——这条"只能选更大"的规则，就是组合去重的全部秘密。

## 关键步骤：选-递归-撤销 三件套

```
for (int i = startIndex; i <= n; i++) {
    path.add(i);                       // ① 选：把 i 放进当前组合
    backtrack(n, k, i + 1, path);      // ② 递归：下一层从 i+1 开始（保证升序，杜绝 [2,1]）
    path.remove(path.size() - 1);      // ③ 撤销：退回去，换下一个 i
}
```

## 终止条件

```
path.size() == k  →  res.add(new ArrayList<>(path)) 然后 return
```

## 两个易错点（面试必考）

1. **`res.add(path)` 存的是引用不是快照**：path 是共用草稿，回溯完被 remove 擦空，res 里最后全变 `[]`。必须 `res.add(new ArrayList<>(path))` 复制一份独立的。
2. **下一层起手必须 `i+1` 不是 `i`**：用 `i` 会产生 `[1,1]`；想消灭排列重复（`[1,2]` 与 `[2,1]`），就靠 `i+1` 强制升序。

## 时空复杂度

| 项目 | 复杂度 | 推导 |
|------|--------|------|
| 时间 | O(C(n,k) × k) | C(n,k) 个组合，每个复制 path 耗时 O(k) |
| 空间 | O(k) | path 深度 = k，递归栈深度 = k |

## Java 代码

```java
class Solution {
    List<List<Integer>> res = new ArrayList<>();

    public List<List<Integer>> combine(int n, int k) {
        backtrack(n, k, 1, new ArrayList<>());
        return res;
    }

    void backtrack(int n, int k, int startIndex, List<Integer> path) {
        if (path.size() == k) {
            res.add(new ArrayList<>(path));   // 复制快照再回溯
            return;
        }
        for (int i = startIndex; i <= n; i++) {
            path.add(i);                      // 选
            backtrack(n, k, i + 1, path);     // 递归（下一层从 i+1 开始）
            path.remove(path.size() - 1);     // 撤销
        }
    }
}
```

## 一句话应用场景

从 n 个候选里选 k 个的所有选法——选课组合、抽奖组合、球队阵容穷举。
