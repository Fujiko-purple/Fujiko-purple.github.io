## 题目
给一棵 BST 和一个值，插入后返回根节点。**保证新值不在树里**。

## 核心思想
BST 插入 = **定向搜索 + 找到空位**：

1. 从根开始，按大小定向走：`val < root.val` 往左，`val > root.val` 往右
2. 走到 **null**（空位）→ 新节点出生：`return new TreeNode(val)`
3. **每一层都把子树的插入结果挂回自己**：`root.left = ...` / `root.right = ...`
4. 返回 root（根节点不变，新节点永远挂在叶子位置）

**为什么新节点永远是叶子**：BST 插入不改变已有节点之间的关系，
只是沿着大小方向找到第一个空位挂上去，不需要像 AVL/红黑树那样旋转调整。

## 关键：递归返回值 = 「这棵子树插入完成后的根」
```
       6
      / \
     2   8
```
插入 5：
1. 6：5<6 → `root.left = insert(左子树, 5)`
2. 2：5>2 → `root.right = insert(2.right=null, 5)`
3. null：空位 → `return new TreeNode(5)`，5 出生
4. 2 层收到 5 → 挂到自己右边
5. 6 层收到「2 整棵子树」→ 挂回左边
6. 返回 6 → 树变成：
```
       6
      / \
     2   8
      \
       5
```

## 为什么每层必须「挂回」（不挂回的后果）
| 空位位置 | 不挂回的后果 |
|---------|-------------|
| 空位在深层（如 2 的右孩子） | 深层自己挂了，这层不挂侥幸没事 |
| 空位就是这层的直接孩子（如 6.left 就是 null） | **新节点悬空丢失，插入失败** |

结论：每一层都挂回，保证无论空位在哪，新节点都能被接住。

## 复杂度
- 时间 O(h)：定向走一条路径（平均 log n，最坏 n）
- 空间 O(h)：递归栈

## Java 代码
```java
class Solution {
    public TreeNode insertIntoBST(TreeNode root, int val) {
        if (root == null) return new TreeNode(val);   // 空位，新节点出生

        if (val < root.val) {
            root.left = insertIntoBST(root.left, val);   // 往左插，挂回左孩子
        } else {
            root.right = insertIntoBST(root.right, val); // 往右插，挂回右孩子
        }
        return root;
    }
}
```

## 易错点
1. **必须挂回**：`root.left = insert(...)` 不能只调用不赋值，否则空位在
   自己这层时新节点丢失
2. 空位判断是 `root == null`，不是 `root.left == null`——递归走到
   null 才停，而不是在父节点判断
3. 这题不需要调整树结构（不是 AVL/红黑树），挂叶子即可
4. 根节点永远不变，直接返回 root；只有空树时返回的是新节点
