## 题目
给定两棵二叉树，将它们合并成一棵新树。合并规则：对应节点都有值则相加，一棵有另一棵没有则直接用非空节点。

```
Tree1:        Tree2:        合并结果：
    1           2              3
   / \         / \            / \
  3   2       1   3          4   5
 /              \           / \   \
5                6          5   6   7
```

## 核心思想
同步前序遍历两棵树。**一棵为空则直接返回另一棵**（连带整棵子树），都不为空则值相加后递归合并左右。

## 关键步骤
1. root1 == null → 返回 root2（可能为 null 也可能是一棵子树）
2. root2 == null → 返回 root1
3. 都不为空 → root1.val += root2.val
4. 递归合并 root1.left 和 root2.left
5. 递归合并 root1.right 和 root2.right
6. 返回 root1

## 时空复杂度

| 项目 | 复杂度 | 推导 |
|------|--------|------|
| 时间 | O(min(n, m)) | 合并到较小树的节点数为止 |
| 空间 | O(h) | 递归栈深度 |

## 模式归类：二叉树-同步遍历合并（短路返回另一棵）

## Java 代码

```java
public TreeNode mergeTrees(TreeNode root1, TreeNode root2) {
    if (root1 == null) return root2;  // root1 为空，root2 整棵子树拿来用
    if (root2 == null) return root1;  // root2 为空，用 root1

    // 都不为空：值相加，递归合并
    root1.val += root2.val;
    root1.left = mergeTrees(root1.left, root2.left);
    root1.right = mergeTrees(root1.right, root2.right);

    return root1;
}
```

### 不修改原树（新建节点版）
```java
public TreeNode mergeTrees(TreeNode root1, TreeNode root2) {
    if (root1 == null && root2 == null) return null;

    int val = (root1 == null ? 0 : root1.val) + (root2 == null ? 0 : root2.val);
    TreeNode root = new TreeNode(val);

    root.left = mergeTrees(root1 == null ? null : root1.left,
                           root2 == null ? null : root2.left);
    root.right = mergeTrees(root1 == null ? null : root1.right,
                            root2 == null ? null : root2.right);

    return root;
}
```

## 易错点
1. ⚠️ `if (root1 == null) return root2`——不是 `return null`，直接返回另一棵子树
2. 两个都是 null 时，`return root2` 自然会返回 null，不需要单独处理
3. 修改原树版面试够用，如果要求不修改原树就用新建节点版
