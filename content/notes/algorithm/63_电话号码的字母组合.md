## 题目

给定一个仅包含数字 2-9 的字符串，返回所有它能表示的字母组合。数字到字母的映射与电话按键相同。

**示例**：`"23"` → `["ad","ae","af","bd","be","bf","cd","ce","cf"]`

```
2→abc  3→def  4→ghi  5→jkl  6→mno
7→pqrs 8→tuv  9→wxyz
```

## 核心思想（一句话）

**每层的候选来自"当前按键"**，不再是同一个数字池——用 `index` 记录轮到第几个按键，逐层递归组字母。

## 与 61 的关键区别：不再需要 i+1

| | 61 组合 | 63 电话 |
|--|--------|--------|
| 每层候选 | 同一个池 `1~n` | **当前按键的字母**（不同层不同池） |
| 去重方式 | `i+1` 强制升序 | **天然不重复**（a 只在第一层，d/e/f 只在第二层） |
| 新参数 | `startIndex` | **`index`**（记录处理到第几个按键） |

三件套换皮：

| 61 组合 | 63 电话 |
|--------|--------|
| `path.add(i)` | `sb.append(字母)` |
| `backtrack(i+1)` | `backtrack(index+1)` ← 下一个**按键** |
| `path.remove(末位)` | `sb.deleteCharAt(末位)` |

## 关键步骤

1. **映射表**：`String[] phone = {"","","abc","def","ghi","jkl","mno","pqrs","tuv","wxyz"}`
   - `phone[2] = "abc"`，`phone[7] = "pqrs"`
2. **取当前按键字母**：`phone[digits.charAt(index) - '0']`（char 转 int 取下标）
3. **三件套**：`sb.append(字母)` → `backtrack(index+1)` → `sb.deleteCharAt(末位)`
4. **终止**：`sb.length() == digits.length()`（每个按键都选了一个字母）→ 收获 `sb.toString()`

## 易错点

- `digits.isEmpty()` 要特判：空串没有组合，返回空列表（不是 `[""]`）
- 字符数字转下标：`digits.charAt(index) - '0'`，`'2'` 变 2
- 收获时 `res.add(sb.toString())`——toString 已生成新 String，无需复制（String 不可变）
- 撤销用 `sb.deleteCharAt(sb.length()-1)`，删的是**当前最后一个**字母

## 时空复杂度

| 项目 | 复杂度 | 推导 |
|------|--------|------|
| 时间 | O(3^m × 4^n) | m=有3字母的按键数，n=有4字母的按键数（7/9） |
| 空间 | O(m+n) | 递归深度 = 按键个数 |

## Java 代码

```java
class Solution {
    String[] phone = {"", "", "abc", "def", "ghi", "jkl", "mno", "pqrs", "tuv", "wxyz"};
    List<String> res = new ArrayList<>();

    public List<String> letterCombinations(String digits) {
        if (digits.isEmpty()) return res;
        backtrack(digits, 0, new StringBuilder());
        return res;
    }

    void backtrack(String digits, int index, StringBuilder sb) {
        if (sb.length() == digits.length()) {      // 每个按键都选了一个字母
            res.add(sb.toString());
            return;
        }
        String letters = phone[digits.charAt(index) - '0'];   // 当前按键的字母
        for (int j = 0; j < letters.length(); j++) {
            sb.append(letters.charAt(j));          // 选：追加字母
            backtrack(digits, index + 1, sb);      // 递归：下一个按键
            sb.deleteCharAt(sb.length() - 1);      // 撤销：删末尾
        }
    }
}
```
